# 人工指定選單圖示

適用版本：Simpilot 0.18.0 及後續版本。

## 功能範圍

「設定 > 選單圖示」頁面可替換主選單或第二選單中可用本機程式與檔案的自動圖示。此功能只負責為單一啟動操作指定圖示，不是完整圖示管理器：不提供圖示包、線上圖示來源、網址圖示、PNG/SVG 轉換、批次操作或分類圖示。

## 選擇圖示

- 選擇一個選單啟動項目，然後按一下「選擇圖示...」。
- Windows 圖示選擇器支援 ICO 檔案，也可瀏覽 EXE 與 DLL 檔案。
- EXE 或 DLL 包含多個圖示時，選擇器會顯示可用圖示並儲存所選索引。
- 所選圖示會轉換為具有透明背景的 128×128 ICO 檔案。轉換完成後，快速啟動選單不再依賴原始圖示來源檔案。

## 儲存與項目識別

自動圖示與人工圖示統一存放於 `Cache\RunIcon`：

```text
Cache/
  RunIcon/
    <target-hash>.ico
    <target-hash>.custom.ico
```

圖示依完整啟動操作區分，包括啟動項目類型、程式或檔案路徑、命令列參數與系統管理員執行狀態。因此，不同 Chrome 設定檔、Chrome 應用程式 ID 或 `explorer.exe shell:::{GUID}` 命令即使使用同一個 EXE，也可以分別指定圖示。只有啟動操作完全相同時，主選單和第二選單中的項目才會共用圖示。

人工圖示的優先順序高於自動快取圖示。「還原自動圖示」只會刪除對應的 `.custom.ico`；下次顯示選單時會重新使用自動圖示。

刪除整個 `Cache\RunIcon` 會同時清除自動圖示快取和所有人工圖示，但不會修改 `Simpilot.ini`、`Simpilot2.ini` 或其他設定。

## 生效方式

選擇或還原圖示後，Simpilot 會立即寫入快取並清除目前選單的記憶體圖示快取。下次開啟快速啟動選單時即可看到更新，不需要重新啟動 Simpilot。

圖示操作會直接修改快取檔案，因此不受設定視窗「儲存」與「取消」按鈕控制。
