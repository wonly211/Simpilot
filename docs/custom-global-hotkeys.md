# 自定义全局热键设计

适用版本：Simpilot 0.18.0 及后续版本

## 1. 功能范围

设置窗口的“全局热键”页显示全部自定义全局热键，并提供添加、编辑和删除操作。列表中的“启用”滑动开关可逐项暂停或恢复热键，不需要删除配置。“操作类型”正式支持：

- “打开应用”：启动可执行文件，可配置参数、工作目录、运行身份、重复启动策略和窗口可见性；
- “打开文件夹”：使用 Windows 文件资源管理器打开目标文件夹；
- “打开文件”：使用 Windows 为该文件类型配置的默认关联程序打开目标文件。

每项共同支持：

- 按键或组合键；
- 操作类型和目标路径；
- 独立的启用或禁用状态。

参数、工作目录、运行身份、应用已运行时的处理方式和窗口可见性只属于“打开应用”。选择“打开文件夹”或“打开文件”时，界面会隐藏这些应用专属选项。

当前版本沿用 0.5.1 引入的单进程键盘架构：`Simpilot.exe` 内的专用键盘线程统一处理运行时热键和设置页录制。该线程拥有独立消息循环并只安装一个 `WH_KEYBOARD_LL`。添加窗口开始录制时，唯一钩子切换到录制优先状态并执行 PowerToys Keyboard Manager 来源的状态逻辑；录制期间输入不会继续传递给 Windows 或其他应用，`Esc` 取消本次录制。关闭“允许组合键”后，只接受不含 Ctrl、Alt、Shift 或 Win 的单键。

## 2. 配置格式

自定义热键写入 `Config\Setting.ini`：

```ini
[CustomGlobalHotkeys]
CustomGlobalHotKeyCount=1
CustomGlobalHotKey1Code=8,71
CustomGlobalHotKey1Force=1
CustomGlobalHotKey1Action=0
CustomGlobalHotKey1Program=C:\Program Files\Example\Example.exe
CustomGlobalHotKey1Arguments=--profile default
CustomGlobalHotKey1WorkingDirectory=C:\Program Files\Example
CustomGlobalHotKey1RunAsAdministrator=0
CustomGlobalHotKey1ExistingProcessAction=0
CustomGlobalHotKey1Visibility=0
CustomGlobalHotKey1Enabled=1
```

`Action` 的值固定为：`0` 打开应用、`1` 打开文件夹、`2` 打开文件。配置键 `Program` 保存当前动作的目标路径；名称保留为 `Program`，但对文件夹和文件同样表示目标路径。

热键只通过 `Code=修饰键,虚拟键` 保存和读取，不兼容文字热键字段。应用动作的 `ExistingProcessAction` 值为：`0` 显示窗口、`1` 启动新实例、`2` 不执行操作；`Visibility` 值为：`0` 正常、`1` 最小化、`2` 最大化、`3` 隐藏。选择“显示窗口”时，简驭会优先恢复已有主窗口；若进程仍在运行但主窗口已经关闭，则重新调用同一路径的程序，由应用自身的单实例机制恢复窗口。文件夹和文件动作不使用这些应用专属字段。`Enabled` 为 `1` 时启用、`0` 时禁用。读取数量上限为 128；缺少 `Code`、`Program` 或 `Enabled` 的项目会被忽略。

## 简驭功能热键

四个不可删除的功能热键统一保存按键与独立启用状态：快捷启动菜单默认使用反引号并启用；第二菜单和设置窗口默认未设置；Everything 搜索默认使用 `Win+S` 且关闭。关闭开关只暂停热键，不会丢失已经录制的组合键；“清除”才会移除组合键并关闭该项。启用 `Win+字母` 后，简驭会自动实时屏蔽对应的 Windows 快捷键。

`[Hotkeys]` 为四项分别保存 `*Code`、`*Force` 和 `*Enabled`。Everything 搜索不保存可执行文件路径，执行时直接调用内部 Everything 管理器：已有默认搜索窗口时将其恢复；否则优先使用已运行默认客户端的来源路径，最后尝试随包的 `Everything\Everything.exe`。启动失败时会显示提示并写入 `Log\Simpilot.log`。

## 3. 冲突与优先级

保存新增项目或修改热键之前，依次检查固定全局热键、已有自定义热键和 Windows/其他应用注册的全局热键。只修改操作类型、目标路径或应用专属属性时，不会重复询问未变化的热键冲突：

1. 与固定全局热键相同时，用户确认后清除原固定设置。
2. 与已有自定义热键相同时，用户确认后替换原项目。
3. 与 Windows 或其他应用已注册热键冲突时，用户确认后进入强制覆盖路径。

精确的 `Win+A`～`Win+Z`（排除 `Win+L`）不显示额外的系统冲突确认，而是自动标记为强制覆盖。`Win+L` 是 Windows 锁定快捷键，添加窗口拒绝保存，配置读取和运行时注册也会再次过滤。

## 4. Win+字母运行时流程

启用的内置或自定义 `Win+字母` 不要求用户在“Windows 快捷键屏蔽”页重复操作。Simpilot 会自动打开并锁定对应开关，同时将它并入常驻 Windows 快捷键屏蔽集合。自动状态不覆盖用户原先的独立屏蔽配置；禁用或编辑掉最后一个使用该组合的热键后，对应项目恢复到用户原先的选择：

1. 唯一的键盘管理器观察动作键，在首次 KeyDown 时向托盘消息窗口投递自定义热键标识。
2. 同一个回调中的 Win 状态机吞掉动作键，注入 `0xFF` dummy key 和 Win KeyUp，并正确处理物理 Win KeyUp 或后续未屏蔽按键的恢复。
3. 托盘消息窗口查找配置索引并执行对应的应用、文件夹或文件动作。

运行时识别、屏蔽和录制由同一专用键盘线程及同一钩子处理，但状态分支互斥。禁用项目不会注册，也不会加入自动屏蔽集合。打开设置窗口时，自定义操作会暂时注销，其对应 Windows 行为仍由运行时分支拦截；开始录制后，录制分支获得最高优先级并吞掉本次输入。保存新增、编辑、启用、禁用或删除操作后，注册和屏蔽状态同步更新。

## 5. 动作执行

### 5.1 打开应用

执行前通过 Tool Help 枚举进程，并用 `QueryFullProcessImageNameW` 按完整可执行文件路径进行不区分大小写的匹配，避免仅按文件名误认其他目录中的同名程序。

- “显示窗口”：找到已有进程后枚举其顶层窗口，恢复最小化窗口并尝试前置；无论是否找到可显示窗口，都不会再启动实例。
- “启动新实例”：不检查已有进程，直接执行。
- “不执行操作”：检测到已有进程后直接返回。

应用通过 `ShellExecuteExW` 启动；管理员身份使用 `runas`，窗口可见性映射到相应的 `SW_*` 显示方式。启动失败只写入 `Log\Simpilot.log`，不在键盘钩子回调中执行文件、进程或日志操作。

### 5.2 打开文件夹与打开文件

文件夹和文件动作使用 `ShellExecuteExW` 的 `open` 操作交给 Windows Shell：文件夹由文件资源管理器打开，文件由系统默认关联程序打开。这两种动作不接收命令行参数，不请求管理员身份，也不会枚举、匹配或复用任何进程。目标不存在或 Windows 没有可用关联程序时，Simpilot 会记录错误并显示失败提示。

## 6. 边界

- 普通桌面应用无法覆盖 `Ctrl+Alt+Del` 等安全注意序列。
- 强制覆盖只在 Simpilot 所在的交互式桌面和权限边界内有效。
- 管理员启动可能显示 UAC 确认；用户取消后应用不会启动。
- 某些应用没有可枚举的顶层窗口，“显示窗口”不会为其创建新实例。
