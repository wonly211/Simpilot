# 全局热键

**简体中文** | [English](../en-US/Global-Hotkeys)

全局热键可在简驭后台运行时，从其他普通桌面程序中直接触发操作。打开“设置 > 全局热键”即可查看、录制、启用或暂停热键。

## 内置热键

简驭提供以下内置功能，每项都可分别录制热键、清除热键并使用开关启用或停用：

| 内置功能 | 作用 |
| --- | --- |
| 快捷启动菜单 | 打开主快捷启动菜单。 |
| 第二菜单 | 打开可选的第二菜单。 |
| 设置 | 打开简驭设置窗口。 |
| Everything 搜索 | 打开或恢复 Everything 搜索窗口。 |

未设置热键或关闭启用开关的功能不会响应组合键。Everything 组件不可用时，简驭仍会正常运行，但“Everything 搜索”热键可能无法完成操作。

## 创建自定义热键

在“自定义全局热键”区域选择“添加”，按以下方式创建操作：

1. 选择操作类型：**打开应用**、**打开文件夹**或**打开文件**。
2. 填写或选择目标路径；打开应用时可额外设置参数、工作目录、管理员权限、重复启动策略和初始窗口状态。
3. 点击录制热键控件，再按下所需组合键。
4. 确认启用开关处于打开状态，然后点击“应用”或“保存”。

创建后可在列表中编辑、删除或临时停用该热键。与快捷启动菜单不同，自定义全局热键不支持直接打开网址；需要打开网站时，请将网址添加到[快捷启动菜单](快捷启动菜单)。

## 自定义热键的激活条件

编辑自定义热键时，可在“激活条件”中分别设置 Caps Lock、Num Lock 和 Scroll Lock 为“不限制”“开启”或“关闭”。默认不限制；设置的锁定键条件必须同时满足。

勾选“仅当下列任一程序正在运行时生效”后，可添加最多 32 个 EXE。按完整路径匹配，不区分大小写；当前登录会话中的后台、最小化和无窗口进程均可匹配，任意一个关联程序运行即可。程序移动目录后需要重新选择；刚启动的程序通常在下一次检测（约半秒）后生效。无法确认进程状态时不会触发。

两类条件同时设置时必须全部满足。条件不满足时，本规则放行按键；已配置的键盘映射和独立 Windows 快捷键屏蔽仍按各自设置工作。长按期间改变条件不会切换动作，也不会重复启动；再次释放并按下后才按新条件判断。锁定键自身作为触发键时，使用按下前的状态，触发成功会消费该次按键。

每条规则可填写“名称／备注”，最多 128 个字符，可留空或重复。列表、完整提示和冲突确认显示名称，名称不影响触发判断。

也可选择“仅当下列任一程序处于前台时生效”，与“正在运行（包括后台）”二选一，复用同一份最多 32 个 EXE 的完整路径列表。前台识别未知时不触发。锁定键条件仍需同时满足。

同一个单键或组合键可对应多条场景规则，例如 Num Lock 开启／关闭时分别打开 A／B，或编辑器／浏览器处于前台时执行不同操作。不同前台程序的名单没有交集时，条件互斥，可以直接共用按键。

两个后台程序可能同时运行，前台与后台规则也可能重叠。需要保留这类规则时，在所有重叠规则中勾选“显式设置同键场景优先级”，填写不同的 0–999 数值；条件同时成立时只执行数值最高的一条，并在保存时确认。相同优先级或只有一条设置优先级仍会提示冲突，不按列表顺序猜测。

没有匹配场景时放行按键。需要默认动作时，请单独添加无锁定键／程序限制的规则，并显式设置较低优先级。例如后台场景设 100、默认动作设 0。每次首次按下固定动作，直到释放；长按或中途切换场景不会重复执行。单独字母 F 在匹配时不会输入字符，请留意编辑器中的提示，优先考虑功能键或组合键。

名称、条件与优先级随全局备份保存和恢复。只使用旧条件时继续保存格式 1；启用前台条件或优先级后使用独立条件记录的格式 2，普通无条件规则仍保留旧格式。v1.0.12 会拒绝读取格式 2，以免忽略新条件误触发；降级前导出备份，并恢复升级前的配置。应用动作中的“程序已运行时”仍是独立的重复启动策略。


## 录制热键

点击录制热键控件后，简驭会进入短暂的按键记录状态。此时直接按下所需组合键，录制结束后输入框会显示结果；按 `Esc` 取消本次录制。录制期间，简驭会临时处理按键事件，避免已支持的组合键同时触发普通应用操作。

录制热键并不等同于一定能注册成功。点击“应用”或“保存”时，简驭会检查组合键是否已被其他简驭热键、Windows 或其他程序占用，并在需要覆盖既有简驭配置时请求确认。

## Windows 热键屏蔽与联动

在“设置 > Windows 快捷键屏蔽”中，可以选择受支持的 `Win+A` 至 `Win+Z` 组合。该功能只在简驭运行时实时拦截键盘事件：不会修改 Windows 系统策略，也不会关闭 Game Bar、反馈中心等 Windows 功能；退出简驭后会自动恢复。

如果启用的内置或无条件自定义热键恰好使用精确的 `Win+字母` 组合，简驭会自动联动并锁定对应的屏蔽项。条件热键仅在条件满足时拦截，不会永久锁定屏蔽开关。用户手动选择的独立屏蔽始终保留，即使条件热键当前不生效也仍会屏蔽系统组合。

屏蔽只匹配精确的 `Win+字母`。例如屏蔽 `Win+Z` 不会影响 `Shift+Win+Z`、`Ctrl+Win+Z` 或 `Alt+Win+Z`。

## 限制与建议

- `Win+L` 是 Windows 安全锁定快捷键，不能被简驭屏蔽或设为全局热键。
- `Ctrl+Alt+Del` 等安全桌面组合不受普通桌面应用控制。
- 登录界面、其他用户会话及部分远程桌面环境不在热键屏蔽的保证范围内。
- 若某个组合已被其他程序注册，请选择不冲突的组合；不要覆盖不了解用途的热键。
- 设置更改后应点击“应用”或“保存”，再测试实际行为。
