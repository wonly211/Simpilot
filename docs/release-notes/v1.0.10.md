# 简驭 | Simpilot v1.0.10

本版支持一条键盘映射关联多个应用，同一套按键设置无需为每个程序重复添加。

## 新增与改进

- 每条映射最多关联 32 个应用，任一关联程序处于前台时生效；仍支持最多 128 条映射规则。
- 适用范围明确区分“所有应用”和“指定应用”。支持逐项添加、浏览 EXE、追加前台应用、自动去重和移除；指定应用列表为空时不能保存，避免误变成全局映射。
- 多应用规则按共同应用检查重复源、修饰键和快捷键前缀冲突，并按同一应用范围检查循环，避免因名单两两重叠而误报循环。
- 冲突会在保存前显示并保留编辑内容。维持应用规则优先于全局、精确优先于前缀、较长匹配前缀优先的行为。
- 保留 Num Lock 和“左 Win → 右 Ctrl”等左右修饰键映射。按住映射键切换应用后，松开源键仍正确释放原目标。
- 调整编辑器滚动与焦点处理，更新简体中文、繁体中文、英文界面及中英文手册、Wiki。

## 使用方法

在“设置 > 键盘映射”添加或编辑规则，选择“指定应用”，逐个添加程序名称（如 `Code.exe`、`notepad.exe`），也可浏览 EXE 或追加前台应用。保存规则后，在设置窗口选择“应用”或“保存”。

例如，“左 Win → 右 Ctrl”关联这两个程序后，仅在其中任一程序处于前台时生效。其他程序可另建不同映射，或使用全局规则。

匹配按 EXE 文件名进行，浏览文件时也仅保存文件名；不区分同名程序的不同路径、窗口或网页。“精确匹配应用”默认开启，关闭后对名单统一采用前缀匹配。本版不包含整套场景配置的一键切换。

## 验证

- Windows x64 Release 全部 27 项测试通过。
- 新增回归覆盖多应用保存和重载、旧配置迁移、损坏列表拒绝、降级读取保护、范围交集与循环、匹配优先级、应用切换后的 Num Lock／修饰键释放，以及 128 条规则 × 32 个应用的上限。
- 原生界面回归覆盖添加、去重、追加前台应用、移除、空列表保护、冲突后保留编辑内容、取消，以及三种语言和 100%／150%／200% 布局与滚动焦点。

## 升级与降级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/` 和 `Cache/RunIcon/`。现有单应用和全局规则直接兼容。

v1.0.9 及更早版本会跳过新建的多应用规则，不会误将它们当成全局。降级前请备份 `Config/`；旧版保存设置可能丢失映射规则，重新升级时建议恢复备份。
