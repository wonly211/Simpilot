# 简驭 | Simpilot v1.0.12

自定义全局热键新增锁定键状态和关联程序运行条件，用于启动程序、打开文件及文件夹。

## 热键激活条件

- Caps Lock、Num Lock、Scroll Lock 各可设置“不限制／开启／关闭”，所设条件必须同时满足。
- 可关联最多 32 个 EXE 完整路径，忽略路径大小写。当前登录会话中任意关联程序运行即满足，包括后台、最小化和无窗口进程；同时设置锁定键条件时，两类条件均须满足。
- 互斥的锁定键条件可以复用同一组合键，例如 Num Lock 开启和关闭分别执行不同操作。不同程序可能同时运行，因此仅程序不同仍会提示冲突。
- 首次按下固定本轮触发或放行结果，长按不重复执行，按住期间改变条件不改选动作。条件 Win 组合键按条件拦截，手动系统快捷键屏蔽独立生效。
- 编辑窗口新增激活条件和程序列表，热键列表显示条件摘要；补齐简体中文、繁体中文、英文及中英文手册和 Wiki。

## 配置与升级

- 旧配置继续按无条件热键读取。有条件热键使用独立版本记录，旧版安全跳过这些规则；降级前请导出全局备份，避免旧版保存时删除新规则。
- 全局备份和目录迁入支持新条件校验；无效条件或不支持的格式明确报错，缺失程序路径保留并提示。
- 原目录覆盖升级时保留 `Config/`、`Cache/`、`Backups/` 和自定义 `Language.lng`。发布 ZIP 不包含用户配置；新目录升级可从旧目录迁入。
- 修复快捷菜单编辑器在部分 DPI 更新场景中未刷新布局的问题。

## 验证与平台说明

- Windows 11 本地 x64 Release 的 30 项自动化测试通过；七个模块逐一关闭和移除全部模块源码的构建、测试及安装清单检查通过。
- 覆盖锁定状态组合、条件互斥与冲突、后台进程启动退出、按下释放、配置兼容、保存回滚和备份恢复。三种语言及 100%／125%／150%／200% DPI 参数布局检查通过。
- Windows 11 隔离探针通过产品钩子检查条件触发和放行；使用测试重放输入，不能视为物理键盘验收。
- **Windows 10 尚未实测。** 真实混合 DPI、高对比度、实际休眠恢复、锁屏／安全桌面切换和条件 Win 组合键的物理输入尚未完成实测。另一登录会话及受保护进程权限场景未实际搭建；未知状态按不满足条件处理的行为已测试。
- 完整范围见功能验收记录（历史内部资料，仅保存在维护者本地备份）。

发布附件为 `Simpilot-1.0.12-win-x64.zip` 和对应 `.sha256` 校验文件。
