# 简驭 | Simpilot v1.0.2

本版修正 v1.0.1 快捷启动菜单中图标、文字偏小和短菜单过宽的问题，恢复旧版紧凑比例，并保留统一视觉设计中的轻量配色。设置窗口、托盘菜单和配置格式不变。

## 菜单改进

- 主菜单、第二菜单和各级子菜单恢复 24 DIP 图标、15 DIP 正常字重文字。
- 恢复与文字高度匹配的行高，统一图标、文字和子菜单箭头预留空间。
- 取消 280 DIP 的强制最小宽度，按各级菜单内容独立定宽；超长名称达到 360 DIP 测量上限后尾部省略。
- 保留用户自定义图标、助记键和原生菜单交互；浅色分隔线保持轻量，深色分隔线降低亮度。

## 验证与已知问题

- 新增 96/144/192 DPI 下的菜单测量回归，覆盖中英文、超长名称、无图标和独立子菜单宽度。
- 真实截图在 150% DPI 下对比 v1.0.0、v1.0.1 渲染器和修订版；另记录浅深主题、上下/左右键、Esc、助记键及右缘根菜单展开。
- 实际 100%/200% DPI、高对比度和全部屏幕边缘组合尚未完成截图验收，尺寸单测不替代实机验证。
- 深色菜单未选中时的系统子菜单箭头对比度偏弱；既有自绘分隔条可能被键盘选中。这两项未在本版修复。

## 升级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/`；使用人工图标时同时保留 `Cache/RunIcon/`。无需重建设置。

发布附件为 `Simpilot-1.0.2-win-x64.zip` 和对应 `.sha256` 校验文件。发布包未进行数字签名。
