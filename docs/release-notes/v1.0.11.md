# 简驭 | Simpilot v1.0.11

本版集中增加全局设置备份与迁移、键盘映射排除应用，以及快捷菜单大小选项。

## 配置保留与恢复

- 常规设置新增导出全部设置、导入备份、从旧版目录迁入，并显示配置目录。
- 单文件备份覆盖各模块设置、两份快捷菜单、图标、输入法记忆、程序选择记录和外部语言文件；保留未知配置字段。
- 首次启动可选择全新使用、迁入旧目录或导入备份。继续使用便携目录；原目录升级可沿用配置，新目录可从旧版迁入。
- 整包恢复前自动备份到 `Backups/`，重启后统一加载。包含完整性校验、规则校验、失败回滚及中断恢复；不会用默认设置覆盖不可读的原配置。
- 备份不包含外部应用、脚本或程序组件；跨电脑和目录恢复时仍需检查应用路径和输入法。

## 键盘映射与菜单显示

- 适用应用新增“排除指定应用”，最多 32 个程序。仅指定应用优先于排除规则，排除规则优先于全局。
- 排除支持精确／前缀匹配，更新冲突及循环检查；前台识别失败时不执行排除规则，跨应用释放键保持正确。
- 快捷启动设置新增“小／中／大”文字与图标大小，统一调整两份菜单及子菜单的布局，并保留 DPI 缩放。默认“中”保持原外观。
- 补齐简体中文、繁体中文、英文界面以及中英文手册和 Wiki。

## 升级与兼容

原目录更新时保留 `Config/`、`Cache/`、`Backups/` 和自定义 `Language.lng`，使新版 `Simpilot.exe` 与 `Everything/` 保持配套。新目录升级时选择旧版目录迁入，旧目录不会被修改。

v1.0.10 及更早版本会跳过排除规则；旧版保存可能删除新规则，降级前请导出备份。旧版不能读取 `.simpilot-backup`，需要使用支持备份格式的版本恢复。

## 验证与平台说明

- Windows 11 本地 Release 构建、29 项自动化测试及模块边界检查通过，覆盖备份往返、文件占用、损坏包、恢复故障、进程中断、映射与菜单 DPI 布局。
- 七个模块逐一关闭，以及移除全部模块源码的构建、测试、安装文件检查通过。
- v1.0.8、v1.0.9、v1.0.10 原始配置读取器兼容探针通过：排除规则被安全跳过，普通映射保持兼容。
- 候选 ZIP 的文件清单、1.0.11.0 版本及 SHA-256 已核对，不含用户配置。
- [云端 CI](https://github.com/wonly211/Simpilot/actions/runs/38043257164) 通过，包含完整测试、模块矩阵及打包；CI 候选包覆盖 v1.0.10 后，7 个配置相关测试文件的 SHA-256 均未改变。
- Windows 11 隔离窗口已检查备份导出、设置布局、菜单字号、长标题、子菜单、滚动入口及深浅色。新增目录权限拒绝和删除第二菜单后进程中断的恢复测试通过。
- 候选 EXE 的恢复启动入口已验证：等待旧进程退出、生成自动备份、恢复原始文件、移除缺失第二菜单，以及再次启动保持配置。设置窗口导入按钮触发完整自动重启的连续桌面操作未单独走通。
- **Windows 10 尚未进行实际交互验收。** 真实混合 DPI 显示器和系统高对比度模式也尚未实测。已按发布负责人确认保留这些限制后集中发布，不能将 CI 或 DPI 参数测试视为这些平台验收通过。详细范围见[验收记录](v1.0.11-validation.md)。

发布附件为 `Simpilot-1.0.11-win-x64.zip` 和对应 `.sha256` 校验文件。
