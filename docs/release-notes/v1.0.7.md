# 简驭 | Simpilot v1.0.7

本版让应用输入法规则的添加更方便：除了选择 EXE 文件，也可以直接选择正在运行的应用。

## 新增与改进

- “设置 > 应用输入法”的添加按钮提供“从文件选择”和“从运行中的应用选择”两个来源；规则编辑框的路径浏览按钮提供相同入口。
- 新选择器默认列出具有可见窗口的应用，包括最小化窗口；可勾选“显示后台进程”查看当前会话中其他可读取路径的进程。
- 支持按程序名、全部窗口标题和完整路径搜索，手动刷新列表；刷新后按程序路径保留选中项。
- 同一 EXE 的多个进程和窗口合并为一项，不同安装路径的同名应用分别显示。完整路径可在列表下方聚焦和复制。
- 异步读取进程列表，不建立常驻进程监视服务，不请求管理员权限；关闭选择器时取消后台任务及延迟回调。
- 选择应用后仍进入原有规则编辑流程。取消不修改草稿，重复路径不覆盖已有规则，功能总开关关闭时也能添加规则。
- 更新简体中文、繁体中文、英文资源和中英文用户手册。功能实现保持在输入法模块内，不向 Shell 或其他模块增加分支。

## 验证与限制

- 本地完整 x64 Release 构建通过全部 25 项测试；输入法模块关闭构建通过全部 22 项测试，模块依赖边界检查通过。
- 原生来源菜单验证了键盘选择和取消；隔离子进程验证了可见及最小化窗口合并、隐藏及工具窗口排除。
- 模拟快照和真实 Win32 对话框测试覆盖去重、搜索、刷新保留选择、空列表、失败重试、长列表滚动、取消和延迟回调失效。
- 三种语言的默认及最小尺寸截图已检查。实际显示缩放为 150%；100% 和 200% 为布局模拟，尚未完成这两种实机缩放及跨显示器 DPI 验收。
- 无法读取完整路径的进程不会出现在列表中。DWM 隐藏窗口、受保护进程、其他用户会话、屏幕阅读器和高对比度仍需补充人工验收。

## 升级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/` 和 `Cache/RunIcon/`。现有 INI、输入法规则和记忆数据无需迁移；输入法功能仍默认关闭，不会因升级自动启用。

发布附件为 `Simpilot-1.0.7-win-x64.zip` 和对应 `.sha256` 校验文件。发布包未进行数字签名。
