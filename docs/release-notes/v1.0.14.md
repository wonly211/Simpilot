# 简驭 | Simpilot v1.0.14

快捷启动菜单增强对 Windows 应用入口的识别和管理，并修复 MSIX/UWP 应用类型与图标显示。

## 应用来源选择

- “打开应用 > 浏览...”现在按以下顺序提供三种来源：“选择已安装的 MSIX/UWP 应用”“浏览可执行文件”“从开始菜单选择”。
- “选择已安装的 MSIX/UWP 应用”只列出当前用户已注册、且具有包身份的 MSIX/UWP 应用。
- “从开始菜单选择”列出 AppsFolder 中全部可启动入口，包括桌面程序、MSIX/UWP 应用和系统应用；跳过分隔项及无有效 AppID 的条目。
- 两种应用列表均显示应用名称、包信息和 AppID。选择后写入 `shell:AppsFolder\<AppID>`，继续使用现有 Windows Shell 启动链路。
- 默认仍选中“浏览可执行文件”，保留原有操作习惯。
- 修复 `shell:AppsFolder\...` 启动项被菜单编辑器误判为“打开文件”的问题；`ms-settings:` 和 `::{GUID}` 同样识别为“打开应用”。

## 菜单图标

- “设置 > 菜单图标”现在会列出 `shell:AppsFolder\<AUMID>`、`ms-settings:` 和 `::{GUID}` 等 Shell 目标。
- Shell 目标通过 `SHParseDisplayName` 和 `IShellItemImageFactory` 提取真实应用图标，不再显示索引 0 的通用文件图标。
- Shell 图标使用内存缓存，不保留可能失效的通用磁盘图标；人工图标和“恢复自动图标”行为保持不变。

## 界面与本地化

- 应用来源选择改为项目自定义模态框，遵循 24/32 标题、28 DIP 边距、72 DIP 底栏、88×36 按钮和共享颜色规范。
- 三项来源使用固定纵向布局，默认焦点保留在“浏览可执行文件”。
- 简体中文、繁体中文和英文资源同步更新；中英文用户手册和 Wiki 已补充应用来源与 Shell 图标说明。

## 兼容与升级

- 不新增配置字段，不改变 `Simpilot.ini`、`Simpilot2.ini` 或 `Setting.ini` 格式。
- 既有 MSIX/UWP 入口继续以 `shell:AppsFolder\<AUMID>` 保存，旧配置可直接读取。
- 原目录覆盖升级时继续保留 `Config/`、`Cache/`、`Backups/` 和自定义 `Language.lng`。
