# 简驭 | Simpilot v1.0.1

本版围绕统一视觉规范改进设置窗口、编辑弹窗和快捷启动菜单，保留 Win32 技术栈、现有 Logo、模块边界及 INI 格式。

## 界面改进

- 统一浅色背景、文字层级、按钮、滑动开关、焦点和列表表头。
- 全局热键采用固定列布局；描述与录制框间距不随窗口变宽，清除和启用操作独立。
- 常规设置限制表单宽度，明确语言立即保存；Everything 使用文字命令按钮；光标定位统一背景与说明层级。
- Windows 快捷键屏蔽按键名、动作和开关对齐，小宽度切换单列并支持滚动定位。
- 列表工具栏改用带名称和提示的图标按钮；关键列保留最小宽度，长路径中间省略，悬停或键盘选行可查看完整值。
- 编辑器和编辑弹窗正文可滚动，不再缩小控件适配窗口；弹窗保存与取消位于独立底部区域。
- 键盘映射区分“适用应用”和“启用此规则”；关于窗口根据文字高度调整。
- 快捷启动菜单统一为 14 DIP 字体、32 DIP 行高和 16 DIP 图标，保留系统菜单交互、深色及高对比度回退。

## 升级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/`；使用人工图标时同时保留 `Cache/RunIcon/`。无需重建现有设置。

本版不提供运行时插件安装，不修改系统安全策略。完整包及 SHA-256 校验文件随版本发布。
