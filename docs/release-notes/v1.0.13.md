# 简驭 | Simpilot v1.0.13

全局热键新增同键多场景与名称备注，可让一个单键或组合键在不同条件下执行不同启动动作。

## 多场景热键与管理

- 每条自定义热键可填写“名称／备注”，最多 128 个字符，可留空或重复。列表、提示及冲突确认显示名称，随配置和全局备份保存。
- 激活条件新增“指定程序处于前台”，按完整 EXE 路径匹配，最多 32 个程序。与后台运行模式二选一，仍可组合三个锁定键条件。
- 不同前台程序或互斥锁定键条件可直接复用按键。可能同时成立的场景需分别设置不同的显式优先级（0–999），只执行当前匹配且数值最高的一条；保存时说明重叠关系并确认。
- 相同优先级或只有一条设置优先级时继续提示冲突。内置热键仍参与冲突检查。
- 没有匹配场景时放行按键；默认动作由用户单独添加并设置较低优先级。每次首次按下固定选择直到释放，长按及中途切换场景不重复执行。
- 单独字母／数字匹配时会占用字符输入，编辑窗口增加提示。简体中文、繁体中文、英文界面及中英文手册／Wiki 同步更新。
- 每次触发分别保留所匹配的具体进程句柄，执行动作前确认该实例仍存活；程序退出并重启不能使旧的待执行动作复活，连续按键的判断也不会互相覆盖。

## 升级与兼容

- 沿用便携配置与全局备份。原目录覆盖升级时保留 `Config/`、`Cache/`、`Backups/` 及自定义 `Language.lng`；新目录可从旧目录迁入。
- v1.0.12 及更早的有效配置可继续读取。只使用旧条件时继续保存条件格式 1；新增前台条件或优先级使用条件格式 2。
- **v1.0.12 不支持格式 2，并会拒绝读取，以免忽略条件误触发。** 降级前导出备份，并恢复升级前配置；更早版本跳过独立条件记录，但保存可能移除这些规则。
- 名称、场景与优先级纳入导入预检和全局恢复。未知格式、无效优先级、缺失条件及冲突明确报错；关联路径缺失时保留并提示。

## 验证与平台说明

- Windows 11 本地 x64 Release 完整 30 项自动化测试通过，覆盖同键优先级、前台范围交集、按下释放、配置兼容、备份恢复及保存失败回滚。
- 三种语言与 100%／125%／150%／200% DPI 参数界面测试通过。
- Windows 11 隔离探针经产品键盘钩子验证双后台场景选择、默认动作、前台切换、按住稳定和进程实例退出后的动作取消。使用带重放标记的测试输入，不等同于物理键盘验收。
- **Windows 10 尚未实测。** 真实混合 DPI、高对比度、实际休眠／安全桌面切换和条件 Win 组合键的物理输入尚未完成实测，保留 v1.0.12 的环境限制。

详细覆盖和未实测环境见[验收记录](../design/hotkey-scenarios-validation.md)。附件为 `Simpilot-1.0.13-win-x64.zip` 和对应 `.sha256` 文件。
