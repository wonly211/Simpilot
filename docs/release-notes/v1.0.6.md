# 简驭 | Simpilot v1.0.6

本版新增应用级输入法状态管理，并取消发布产物的 5% 体积增长门槛。

## 新增与改进

- 新增“设置 > 应用输入法”页面，功能默认关闭。按完整 EXE 路径选择“指定输入法”“自动记忆”或“不干预”。
- 固定规则在切入应用时选择输入法及中文/英文模式；没有固定规则的应用恢复最近记录的状态，首次没有历史时保持原状态。
- 自动记忆保存在 `Config/InputMethodHistory.ini`，跨重启保留，独立于设置草稿。取消不保存未应用的规则。
- 每次进入应用只尝试一次规则，用户仍可手动切换。同一 EXE 的不同窗口不重复应用。
- 输入法卸载、权限不足或目标拒绝切换时保留规则，仅通过页面状态和日志报告，不反复弹窗。
- 输入法模块静态编译，可通过 `SIMPILOT_MODULE_INPUT_METHOD=OFF` 移除，无需修改 Shell、设置宿主或其他模块。
- 发布体积保留历史基线、字节差值及增长比例统计，增长不再阻断发布或要求审批。版本、测试、模块边界、发布包白名单和 SHA-256 检查保持不变。
- 更新简体中文、繁体中文和英文资源及中英文用户说明。

## 验证与限制

- 输入法实现阶段的完整 Release 构建通过全部 23 项测试；禁用输入法构建通过 21 项测试，七模块关闭矩阵及源码移除演练通过。
- 新增体积策略回归：超过原 5% 门槛仍可生成报告，保留无效基线及版本检查。
- 隔离的跨进程微软拼音探针完成英文、中文、英文模式切换并读回确认。
- 隔离设置页覆盖三种策略、取消、不可用输入法、长路径、列表滚动、多语言和保存失败回滚；实际编辑框验证为 150% DPI，100%/200% 页面为模拟布局尺度，不代替实机多显示器验收。
- 第一版重点支持微软拼音。部分第三方输入法、高权限窗口和不接受切换的程序可能不支持控制。规则约每 200 ms 采样，不保证捕获更短的访问或状态变化。
- 记事本、浏览器、编辑器之间的实际操作、输入法卸载、管理员窗口及 100%/200% 实机 DPI 手工验收尚未完成，不宣称全部场景兼容。

## 升级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/` 和 `Cache/RunIcon/`。现有 INI 无需修改；新输入法功能需手动启用。

发布附件为 `Simpilot-1.0.6-win-x64.zip` 和对应 `.sha256` 校验文件。发布包未进行数字签名。
