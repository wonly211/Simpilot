# 简驭 | Simpilot v1.0.3

本版修复设置窗口中菜单图标索引和快捷启动编辑器的滚动问题。保留 v1.0.2 的快捷启动菜单比例、现有配置格式和启动行为。

## 修复

- 菜单图标按完整菜单名称及助记键索引，不再按应用或启动命令合并。`Google Chrome(&H)` 和 `Google Chrome(&O)` 分别显示为 `Google Chrome(H)`、`Google Chrome(O)`，可以独立设置或恢复图标。
- 更改启动目标、参数、程序解析路径或管理员运行选项，不影响同一完整菜单名称的自定义图标。
- 兼容迁移旧版按命令和名称保存的自定义图标，保留已明确设置的新图标和旧文件归档；恢复自动图标后不会在重新加载时再次导入旧覆盖。
- 快捷启动编辑器保持菜单切换按钮、左侧菜单树和结构工具栏固定，仅右侧详情按实际内容滚动。
- 切换分类、分隔线和网站项目时，不再为隐藏字段预留滚动空间；修正隐藏页面的解析路径布局，并保留键盘焦点自动滚入视区和字段 Tab 顺序。

## 验证与边界

- 全部 21 项测试通过，新增完整菜单名称、助记键独立图标、旧图标迁移及右侧独立滚动回归。
- 滚动布局覆盖 96/144/192 DPI 的尺寸测试；150% DPI 的隔离原生预览确认左右滚动独立、分类滚动条收起，以及两个 Chrome 菜单项同时显示。
- 实际 100%/200% DPI 和高对比度截图未重新验证。v1.0.2 记录的深色菜单系统箭头对比度及分隔条键盘选中问题不在本版修复范围。

## 升级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/` 和 `Cache/RunIcon/`。现有 INI 无需修改；旧自定义图标会在菜单加载时兼容迁移。

发布附件为 `Simpilot-1.0.3-win-x64.zip` 和对应 `.sha256` 校验文件。发布包未进行数字签名。
