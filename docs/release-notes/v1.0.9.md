# 简驭 | Simpilot v1.0.9

本版修复无法将“左 Win”映射为“右 Ctrl”等单独修饰键的问题。

## 修复与改进

- 左/右 Ctrl、Alt、Shift、Win 均可作为单键目标，支持下拉选择、录制、保存和重新加载。
- 单键映射到修饰键时立即按住目标，释放源键时释放目标，支持快速组合键和不同按下、释放顺序。例如“左 Win → 右 Ctrl”后可使用左 Win 配合 `C` 发送 `Ctrl+C`；也支持 `Caps Lock → 左 Ctrl`。
- 修正共享目标修饰键的释放处理，多个映射源或真实目标键同时按住时，避免提前释放。关闭、更新映射时清理仍按住的目标。
- 修饰键目标不会因源键自动重复而重复发送，扩展标志保留左右按键区别。
- 保留修饰键映射到普通键或快捷键时的短按判定，例如“右 Ctrl → Copilot”；Num Lock 映射功能继续保留。
- 更新简体中文、繁体中文、英文提示，以及中英文用户手册和键盘映射 Wiki。

## 使用方法

“左 Win → 右 Ctrl”：源主键选择“左 Win”，目标主键选择“右 Ctrl”，两侧修饰键槽均保持“无”，保存规则后应用设置。也可分别录制这两个单键。

修饰键作为目标主键时不能再添加其他目标修饰键。修饰键映射到另一个修饰键时，不能同时配置包含同一源修饰键的源快捷键。

## 验证

- Windows x64 Release 全部 25 项测试通过。
- 新增回归覆盖八个左右修饰键目标的“录制 → 编辑 → 保存 → 重新加载 → 执行”、快速组合、释放顺序、共享目标、自动重复及映射更新清理。
- 原生 Windows 探针使用实际映射引擎，确认系统正确识别八个左右修饰键的目标按下和释放事件。
- 保留 Num Lock、Copilot 快捷键、输入发送失败清理和 Windows 安全组合的回归验证。
