# 简驭 | Simpilot v1.0.5

本版修复快捷启动菜单图标选择的取消逻辑，并支持导入常见图片格式。

## 修复与改进

- 双击菜单图标项后取消或关闭选择框，不再将“自动”图标误改为“自定义”，也不会产生待保存修改。
- 图标选择支持 PNG、JPG/JPEG、BMP、GIF、TIFF 和 ICO；继续支持从 EXE、DLL 中选择图标索引。
- 图片导入保留透明度和宽高比例，居中转换为 128×128 ICO，沿用现有自定义图标缓存与设置保存事务。
- 损坏、缺失的图片或保存失败不会覆盖原图标；导入成功后不再依赖原始图片文件。
- 更新简体中文、繁体中文、英文筛选文案及中英文用户说明。

## 验证

- 本地 MSVC x64 Release 构建成功，全部 21 项测试通过。
- 新增真实文件选择框及 EXE/DLL 图标框的取消和关闭回归，覆盖自动图标、自定义图标和设置草稿不变。
- 覆盖所有新增图片格式、PNG 透明度、横竖图片宽高比例、原始文件移除、损坏或缺失文件、保存失败与重试，以及 COM 生命周期。
- 使用隔离夹具在 150% DPI 检查双击与取消：图标来源保持“自动”，应用按钮不启用。
- 图片选择的手动端到端验证未完成；图片解码、转换及保存由自动测试覆盖，不宣称全状态人工验收。

## 升级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/` 和 `Cache/RunIcon/`。现有 INI 无需修改。

发布附件为 `Simpilot-1.0.5-win-x64.zip` 和对应 `.sha256` 校验文件。发布包未进行数字签名。
