# 简驭 | Simpilot v1.0.4

本版修复快捷启动菜单设置页启动项编辑区域的滚动条交互和布局问题。

## 修复

- 右侧启动项详情使用原生 Win32 滚动窗口，滚动条现在可以正常点击、拖动和使用箭头操作。
- 启动项详情不会再吞掉滚动条的鼠标命中，左侧菜单树和结构工具栏继续保持固定。
- “启动项”标题与“主菜单 / 第二菜单”切换区域顶部对齐。
- 增加启动项详情可用高度，减少编辑字段被滚动条遮挡或需要频繁滚动的情况。

## 验证

- 全部 21 项测试通过。
- 覆盖 96/144/192 DPI 下的滚动布局、原生滚动条命中、箭头滚动、鼠标滚轮、键盘焦点滚动和 Tab 顺序。
- 使用隔离预览夹具在 150% DPI 实际点击和拖动滚动条，确认详情区域可滚动且左侧菜单树不移动。

## 升级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/` 和 `Cache/RunIcon/`。现有 INI 无需修改。

发布附件为 `Simpilot-1.0.4-win-x64.zip` 和对应 `.sha256` 校验文件。发布包未进行数字签名。
