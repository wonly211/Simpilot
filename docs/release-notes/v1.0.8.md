# 简驭 | Simpilot v1.0.8

本版修复 Num Lock 目标按键保存后不生效的问题，并补齐数字锁定键的录制显示和下拉选择。

## 修复与改进

- 修复录制 Num Lock 后显示 `VK 0x90` 的问题。简体中文显示“数字锁定 (Num Lock)”，繁体中文和英文同步补齐名称。
- 源主键、目标主键和源同时按下键的下拉列表加入 Num Lock，也可继续使用按键录制。
- 修正 Num Lock 的输入发送方式，映射目标能正确切换数字锁定状态；未完成的源组合回放 Num Lock 时使用相同处理。
- 此前保存的 `VK 0x90` 目标配置可直接使用，无需重新录制或修改 INI。
- 更新中英文用户手册及键盘映射 Wiki 源页面。

## 验证

- Windows x64 Release 构建通过全部 25 项测试，覆盖 Num Lock 作为源键、目标键和组合前缀回放。
- 回归测试覆盖“录制 → 编辑 → 保存 → 重新加载 → 执行”，以及已有扩展扫描码和仅虚拟键码的目标配置。
- 原生 Windows 探针使用实际映射引擎，确认系统收到正确的 Num Lock 按下和释放事件；数字锁定状态实测为“关 → 开 → 关”，测试结束恢复原状态。

## 升级

退出旧版后替换程序文件和 `Everything/`，保留 `Config/` 和 `Cache/RunIcon/`。现有配置无需迁移。

发布附件为 `Simpilot-1.0.8-win-x64.zip` 和对应 `.sha256` 校验文件。发布包未进行数字签名。
