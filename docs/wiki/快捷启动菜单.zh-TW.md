# 快速啟動選單

[简体中文](快捷启动菜单) | **繁體中文** | [English](快捷启动菜单.en-US)

快速啟動選單用於集中管理常用入口。按一下简驭通知區域圖示即可開啟主選單；選單會依滑鼠位置和目前顯示器可用空間自動選擇展開方向。

## 開啟選單編輯器

在通知區域圖示按右鍵，選擇「設定」，再進入「快速啟動選單」。此頁面同時管理主選單和選用的第二選單。

- **主選單**儲存於 `Config/Simpilot.ini`，可透過通知區域圖示或主選單快速鍵開啟。
- **第二選單**儲存於 `Config/Simpilot2.ini`，建立內容後才會依需要產生，可單獨設定快速鍵。

如需先瞭解程式入口和預設操作，請閱讀[快速開始](快速开始.zh-TW)。如需使用快速鍵開啟選單，請閱讀[全域快速鍵](全局热键.zh-TW)。

## 建立選單結構

左側目錄樹用於選取項目和調整結構，樹狀目錄上方可新增三種內容：

| 類型 | 用途 |
| --- | --- |
| 分類 | 建立可繼續包含子項目的分層選單。 |
| 啟動項目 | 建立實際執行的入口。 |
| 分隔線 | 在同層級項目之間形成視覺分組。 |

選取項目後，可直接在右側修改名稱、目標和其他屬性。透過目錄樹下方的「上移」「下移」「升級」「降級」調整順序和層級。分類和啟動項目可設定選單存取鍵；同一層級中重複的存取鍵會被提示，以避免選單操作衝突。

## 新增啟動項目

啟動項目支援以下動作類型：

| 動作類型 | 適用情境 |
| --- | --- |
| 開啟應用程式 | 啟動程式，也可設定參數、工作目錄、系統管理員權限、重複啟動策略和初始視窗狀態。 |
| 開啟資料夾 | 使用 Windows 檔案總管開啟目標資料夾。 |
| 開啟檔案 | 使用 Windows 預設關聯程式開啟目標檔案。 |
| 開啟網站 | 使用預設瀏覽器造訪網址。 |

應用程式目標可填寫完整路徑。若啟動項目只填寫程式名稱，简驭會先嘗試 Windows 系統目錄和 `PATH`，必要時再透過 Everything 定位。找到多個候選程式時，會顯示路徑、版本和修改時間，供你選擇正確檔案；選擇結果會被快取。

Everything 無法使用不會阻止選單啟動，但未填寫完整路徑的程式可能無法自動定位。更多說明請參閱[Everything 整合](Everything-集成.zh-TW)。

## 圖示與外觀

简驭會為可解析的本機啟動項目自動擷取圖示，並快取到 `Cache/RunIcon/`；缺少原生大圖示時會自動縮放。也可以在「設定 > 選單圖示」中，從 ICO 檔案或 EXE、DLL 手動指定圖示。

手動圖示會以完整啟動操作為單位儲存，因此同一個 EXE 使用不同參數時可分別指定圖示。網址、分類和分隔線不支援手動指定圖示。

選單佈景主題可在「設定 > 一般」中選擇：跟隨 Windows、淺色或深色。此設定只影響简驭選單，不會修改系統佈景主題。

## 儲存與重新整理

按一下「套用」會儲存並保持設定視窗開啟；按一下「儲存」會儲存並關閉視窗；「取消」會放棄尚未套用的變更。简驭會自動監視 `Simpilot.ini` 和 `Simpilot2.ini` 的變更並重新整理選單。讀取新設定失敗時，程式會保留上一份有效選單，以避免選單突然消失。

手動編輯設定檔時，請使用 UTF-8 編碼，並在通知區域右鍵選單的「維護 > 重新整理選單」中手動重試。一般情況下更建議透過編輯器修改選單。
