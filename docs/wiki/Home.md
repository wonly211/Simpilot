**简体中文** | [繁體中文](首頁) | [English](Home.en-US)

简驭 | Simpilot 是面向 Windows 的轻量级快速启动器和全局热键管理器。它以通知区域图标为入口：把常用应用、文件夹、文件和网站组织为分层菜单，也可以用全局热键直接执行高频操作。

## 从这里开始

第一次使用请阅读[快速开始](快速开始)，完成下载、解压和首次启动。简驭是便携式程序，不提供传统主窗口；启动后会常驻 Windows 通知区域。

- 左键单击托盘图标：打开快捷启动菜单。
- 右键单击托盘图标：打开设置、语言、Everything 维护、关于和退出等管理操作。
- 托盘图标未直接显示时：请展开 Windows 任务栏的隐藏图标区域。

## 核心能力

- **快捷启动菜单**：支持分类、分隔线，以及应用、文件夹、文件和网址启动项。
- **全局热键**：可快速打开菜单、设置窗口、Everything，或执行自定义操作。
- **Windows 热键屏蔽**：在简驭运行期间实时拦截选定的 `Win+字母` 组合；不修改 Windows 系统策略，退出简驭后自动恢复。
- **Everything 集成**：可打开或恢复 Everything，并帮助定位未填写完整路径的程序。
- **本地化**：简体中文、繁体中文和英文内置于程序；可选的 `Language.lng` 可提供其他界面语言。
