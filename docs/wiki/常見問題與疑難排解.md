# 常見問題與疑難排解

[简体中文](常见问题与故障排查) | **繁體中文** | [English](FAQ-and-Troubleshooting)

## 啟動後沒有主視窗

這是正常行為。简驭 | Simpilot 常駐在 Windows 通知區域，不會顯示一般主視窗。

1. 查看工作列右側的通知區域及「隱藏的圖示」。
2. 按一下通知區域圖示開啟快速啟動選單；按右鍵開啟設定和維護選單。
3. 若完全找不到圖示，確認已完整解壓縮發佈套件、程式目錄可寫入，並查看 `Log/Simpilot.log`。

## 通知區域圖示消失

Windows 檔案總管重新啟動後，简驭會嘗試自動重新註冊通知區域圖示。請稍候片刻；仍未出現時，結束並重新啟動 `Simpilot.exe`，再查看記錄檔。

## 快速啟動選單缺少項目

简驭會隱藏不存在或無法解析的目標。請檢查：

- 目標路徑是否存在；
- 相對路徑是否相對於 `Config/` 填寫正確；
- 程式名稱是否能在 Windows 一般搜尋路徑、`PATH` 或 Everything 中找到；
- 選單檔案是否為有效 UTF-8。

修正後可等待自動重新整理，或在通知區域圖示按右鍵後選擇「維護 > 重新整理選單」。設定讀取失敗時，简驭會保留上一份有效選單。

## 全域快速鍵沒有回應

1. 在「設定 > 全域快速鍵」確認快速鍵已錄製且開關已啟用。
2. 按一下「套用」或「儲存」。
3. 關閉設定視窗後再測試。
4. 檢查是否與其他程式或 Windows 快速鍵衝突。
5. 改用未被系統保留的組合，並查看 `Log/Simpilot.log` 中的快速鍵註冊錯誤。

`Win+L`、`Ctrl+Alt+Del` 等 Windows 安全性組合不能作為简驭快速鍵，也不能由一般桌面程式封鎖。

## Windows 快速鍵仍會執行

在「設定 > Windows 快速鍵封鎖」中開啟對應 `Win+字母` 開關，並按一下「套用」或「儲存」。此功能只封鎖精確組合，例如封鎖 `Win+Z` 不會影響 `Shift+Win+Z`。

封鎖只在简驭執行期間生效，結束後自動恢復，不需要重新啟動 Windows 檔案總管。登入畫面、其他使用者工作階段、安全桌面和部分遠端桌面環境不在保證範圍內。

## Everything 搜尋無法開啟或無法定位程式

1. 確認 `Everything/Everything.exe` 和 `Everything/Everything64.dll` 都存在。
2. 在通知區域圖示按右鍵，選擇「維護 > 開啟 Everything」。
3. 若需要索引服務，選擇「維護 > 安裝/修復 Everything 服務...」，並在權限確認視窗中允許操作。
4. 如只使用具名 Everything 執行個體，請啟動預設執行個體，或使用隨附 Everything。

Everything 無法使用不會阻止简驭啟動，只會影響 Everything 搜尋和無完整路徑程式的定位。更多規則請見 [Everything 整合](Everything-整合)。

## 設定的語言沒有出現

簡體中文、繁體中文和 English 已內建。其他語言需要將 `Language.lng` 放在 `Simpilot.exe` 同目錄，然後重新啟動简驭。

若仍未出現，通常是語言包檔名、位置或格式不正確。刪除或移走有問題的 `Language.lng` 後，简驭會正常回退到內建語言。詳見[語言與 Language.lng](語言與-Language.lng)。

## 選單圖示不正確或沒有更新

在「設定 > 選單圖示」中重新選擇圖示或還原自動圖示。自動圖示和人工圖示都儲存在 `Cache/RunIcon/`。刪除此目錄可以重建圖示快取，但會同時刪除人工指定圖示。

## 回報問題時應提供什麼

請在 [GitHub Issues](https://github.com/wonly211/Simpilot/issues) 中描述：Windows 版本、简驭版本、重現步驟、預期結果、實際結果，以及相關記錄檔片段。請先清理記錄檔中的個人路徑、使用者名稱和敏感檔案名稱。
