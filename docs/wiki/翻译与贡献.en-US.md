# Translating and Contributing

[简体中文](翻译与贡献) | [繁體中文](翻译与贡献.zh-TW) | **English**

Thank you for helping make Simpilot available in more languages. Simplified Chinese, Traditional Chinese, and English are built in. Other languages are distributed through `Language.lng`.

## Report an issue or suggestion

Submit feature ideas, defect reports, and translation issues through [GitHub Issues](https://github.com/wonly211/Simpilot/issues). Include the Simpilot version, Windows version, clear reproduction steps, and the expected outcome. Before attaching a log, remove personal directories, usernames, and sensitive filenames.

## Create a translation source file

1. Copy `Languages/en-US.json` in the repository as a template, for example to `fr-FR.json`.
2. Save it in UTF-8 and retain the complete set of string keys.
3. Provide the locale, the language's self-name, and each interface string.

The minimum structure is:

```json
{
  "locale": "fr-FR",
  "name": "Francais",
  "strings": {
    "ui.settings": "Parametres"
  }
}
```

- `locale` should use a language and region code such as `fr-FR`.
- `name` is the self-name shown in Settings and should be written in that language.
- `strings` must use the complete key set from `Languages/en-US.json`. Missing keys fall back to English but should not be left out of a release-quality translation.

Do not translate the brand name **Simpilot**, product filenames, configuration filenames, command-line parameters, or code keys.

## Generate Language.lng

The repository provides the build-time tool `tools/language_pack_builder.cpp`. Build it in a Windows CMake build directory:

```powershell
cmake -S . -B build/vs2022-x64 -G "Visual Studio 17 2022" -A x64
cmake --build build/vs2022-x64 --config Release --target simpilot_language_pack_builder
```

Then pack a JSON translation source file:

```powershell
.\build\vs2022-x64\Release\simpilot_language_pack_builder.exe `
  .\Language.lng .\fr-FR.json
```

You can include several translation source files in one package:

```powershell
.\build\vs2022-x64\Release\simpilot_language_pack_builder.exe `
  .\Language.lng .\fr-FR.json .\de-DE.json
```

The result, `Language.lng`, is a compressed binary file. Place it beside `Simpilot.exe`, restart Simpilot, then select the new language under **Settings > General > Display Language**.

## Validation checklist

Before submitting a translation, verify that:

- the application, tray menu, Settings, editor, and dialogs do not have obvious untranslated English text;
- text does not truncate or overlap at common display scales;
- hotkeys, filenames, variables, and formatting placeholders are preserved;
- the target language appears when `Language.lng` is beside the executable; and
- Simpilot still starts with its built-in languages when `Language.lng` is removed or damaged.

## Submit a translation

Submit the JSON source file and any needed notes to the repository rather than only the binary `Language.lng`. Maintainers can then review key completeness, terminology, UI presentation, and the final packaged result before distributing the language with a release.

For user-facing behavior of language packages, see [Language and Language.lng](语言与-Language.lng.en-US).
