# Windows 快速鍵封鎖

[简体中文](Windows-快捷键屏蔽) | **繁體中文** | [English](Windows-Hotkey-Blocking)

「設定 > Windows 快速鍵封鎖」用於選擇需要由简驭即時攔截的受支援 `Win+字母` 組合。

## 運作方式

- 封鎖只在简驭執行期間有效；結束简驭後立即恢復 Windows 原有行為。
- 简驭攔截鍵盤事件，不修改 Windows 原則、登錄或系統功能。
- 不需要重新啟動 Windows 檔案總管。
- 每個組合使用獨立滑動開關；修改後請按一下「套用」或「儲存」。

例如，封鎖 `Win+Z` 不會影響 `Shift+Win+Z`、`Ctrl+Win+Z` 或 `Alt+Win+Z`。

## 與全域快速鍵的連動

當啟用的內建或自訂快速鍵使用精確的 `Win+字母` 時，简驭會自動封鎖對應 Windows 快速鍵，並優先執行該快速鍵動作。設定頁會顯示此項已由全域快速鍵啟用。

停用、清除或刪除最後一個使用該組合的全域快速鍵後，自動連動會解除；你先前手動設定的封鎖狀態仍會保留。

## 限制

- `Win+L` 是 Windows 安全性鎖定快速鍵，不提供封鎖或全域快速鍵設定。
- `Ctrl+Alt+Del` 等安全桌面組合無法由一般桌面程式截獲。
- 登入畫面、其他使用者工作階段、權限更高的桌面和部分遠端桌面環境不在保證範圍內。
