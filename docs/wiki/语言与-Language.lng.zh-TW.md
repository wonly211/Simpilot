# 語言與 Language.lng

[简体中文](语言与-Language.lng) | **繁體中文** | [English](语言与-Language.lng.en-US)

简驭 | Simpilot 內建簡體中文、繁體中文與 English。首次執行以及語言設定無效時，預設使用簡體中文。

內建語言已經以壓縮資源形式存入 `Simpilot.exe`，發佈目錄不需要 `Languages` 資料夾。刪除、移動或損壞選用的外部語言包都不會影響三種內建語言，也不會阻止程式啟動。

## 切換內建語言

1. 在通知區域圖示按右鍵，選擇「設定...」。
2. 開啟「一般」。
3. 在「顯示語言」中選擇簡體中文、繁體中文或 English。

選擇後介面會立即切換，不需要重新啟動简驭。設定會儲存到 `Config/Setting.ini`。快速啟動選單標題、分類名稱和路徑屬於使用者資料，不會自動翻譯。

## 使用其他語言

其他語言透過選用檔案 `Language.lng` 提供。請將它放在 `Simpilot.exe` 同一目錄：

```text
Simpilot.exe
Language.lng
Everything/
Config/
```

重新啟動简驭後，包內語言會出現在「設定 > 一般 > 顯示語言」中。一個 `Language.lng` 可以包含一種或多種額外語言。

若 `Language.lng` 不存在、格式錯誤、版本不相容或無法解壓縮，简驭會直接忽略該檔案並繼續使用內建語言。外部語言包只能增加語言，不能取代簡體中文、繁體中文或 English。

## 檔案格式

`Language.lng` 是壓縮的二進位語言包，不是可直接編輯的文字檔。它使用固定檔案標頭和 XPRESS Huffman 壓縮負載，目的是避免在發佈目錄中直接暴露 JSON 文字，並減少資源體積。

這不是加密或安全措施。需要修改翻譯時，應編輯 JSON 原始檔後重新打包，而不是嘗試修改 `.lng` 檔案。

## 翻譯缺失時的顯示

每一段介面文字按以下順序取得：

```text
所選語言 -> 內建 English -> [missing translation]
```

因此，外部語言包即使漏掉少量字串，介面也不會出現空白控制項；但正式發佈前仍應補齊所有翻譯項目。

如何製作與發佈新語言，請參閱[翻譯與貢獻](翻译与贡献.zh-TW)。
