# 翻译与贡献

**简体中文** | [繁體中文](翻译与贡献.zh-TW) | [English](翻译与贡献.en-US)

感谢您帮助简驭 | Simpilot 支持更多语言。程序内建简体中文、繁体中文和 English；其他语言通过 `Language.lng` 提供。

## 提交问题与建议

功能建议、缺陷报告和翻译问题请提交到 [GitHub Issues](https://github.com/wonly211/Simpilot/issues)。请提供简驭版本、Windows 版本、清晰的复现步骤和预期结果。涉及日志时，请先删除个人目录、用户名和敏感文件名。

## 创建翻译源文件

1. 以仓库中的 `Languages/en-US.json` 为模板创建语言文件，例如 `fr-FR.json`。
2. 使用 UTF-8 编码保存，并保留全部字符串键。
3. 填写语言代码、语言自称和每条界面文本。

最小结构如下：

```json
{
  "locale": "fr-FR",
  "name": "Francais",
  "strings": {
    "ui.settings": "Parametres"
  }
}
```

- `locale` 使用类似 `fr-FR` 的语言和区域代码。
- `name` 是设置页中显示的语言自称，应使用该语言自己的文字。
- `strings` 必须以 `Languages/en-US.json` 的完整键集为基准。漏掉的键会回退到 English，但不应作为正式翻译发布。

请不要翻译品牌名“简驭 | Simpilot”、产品文件名、配置文件名、命令行参数或代码键名。

## 生成 Language.lng

仓库提供构建期工具 `tools/language_pack_builder.cpp`。先在 Windows 的 CMake 构建目录生成该工具：

```powershell
cmake -S . -B build/vs2022-x64 -G "Visual Studio 17 2022" -A x64
cmake --build build/vs2022-x64 --config Release --target simpilot_language_pack_builder
```

再使用工具打包 JSON 源文件：

```powershell
.\build\vs2022-x64\Release\simpilot_language_pack_builder.exe `
  .\Language.lng .\fr-FR.json
```

可一次加入多份翻译源文件：

```powershell
.\build\vs2022-x64\Release\simpilot_language_pack_builder.exe `
  .\Language.lng .\fr-FR.json .\de-DE.json
```

生成的 `Language.lng` 是压缩二进制文件。将它放到 `Simpilot.exe` 同目录，重启简驭后即可在“设置 > 常规 > 显示语言”中选择新语言。

## 验证清单

提交前请确认：

- 应用启动、托盘菜单、设置、编辑器和对话框没有明显的英文残留；
- 文本在常见显示缩放下不截断，按钮文字不重叠；
- 快捷键、文件名、变量和格式化占位符保持原样；
- `Language.lng` 放在程序同目录后能显示目标语言；
- 移走或损坏 `Language.lng` 后，简驭仍能正常启动并使用内建语言。

## 提交翻译

建议将 JSON 源文件和必要的说明一并提交到仓库，而不是只提交二进制 `Language.lng`。维护者会复核键完整性、术语一致性、界面显示和打包结果，再将语言包随相应发布版本提供。
