# 快捷启动菜单

**简体中文** | [繁體中文](快速啟動選單) | [English](Quick-Launch-Menu)

快捷启动菜单用于集中管理常用入口。左键单击简驭托盘图标即可打开主菜单；菜单会根据鼠标位置和当前显示器可用空间自动选择展开方向。

## 打开菜单编辑器

右键单击托盘图标，选择“设置”，再进入“快捷启动菜单”。此页面同时管理主菜单和可选的第二菜单。

- **主菜单**保存于 `Config/Simpilot.ini`，可通过托盘左键或主菜单热键打开。
- **第二菜单**保存于 `Config/Simpilot2.ini`，创建内容后按需生成，可单独设置热键。

如需先了解程序入口和默认操作，请阅读[快速开始](快速开始)。如需用热键打开菜单，请阅读[全局热键](全局热键)。

## 建立菜单结构

左侧目录树用于选择项目和调整结构，树上方可添加三种内容：

| 类型 | 用途 |
| --- | --- |
| 分类 | 创建可继续包含子项目的分层菜单。 |
| 启动项 | 创建实际执行的入口。 |
| 分隔线 | 在同级项目之间形成视觉分组。 |

选中项目后，在右侧直接修改名称、目标和其他属性。通过目录树下方的“上移”“下移”“升级”“降级”调整顺序和层级。分类和启动项可设置菜单访问键；同一层级中重复的访问键会被提示，以避免菜单操作冲突。

## 添加启动项

启动项支持以下操作类型：

| 操作类型 | 适用场景 |
| --- | --- |
| 打开应用 | 启动程序，也可设置参数、工作目录、管理员权限、重复启动策略和初始窗口状态。 |
| 打开文件夹 | 使用 Windows 资源管理器打开目标文件夹。 |
| 打开文件 | 使用 Windows 默认关联程序打开目标文件。 |
| 打开网址 | 使用默认浏览器访问网址。 |

应用目标可以填写完整路径。对于只填写程序名称的启动项，简驭会先尝试 Windows 系统目录和 `PATH`，必要时再通过 Everything 定位。若找到多个候选程序，会显示路径、版本和修改时间，供你选择正确的文件；选择结果会被缓存。

Everything 不可用不会阻止菜单启动，但未填写完整路径的程序可能无法自动定位。更多说明请参阅[Everything 集成](Everything-集成)。

## 图标与外观

简驭会为可解析的本地启动项自动提取图标并缓存到 `Cache/RunIcon/`，缺少原生大图标时会自动缩放。也可以在“设置 > 菜单图标”中，从 ICO 文件或 EXE、DLL 中手动指定图标。

手动图标以完整启动操作为单位保存，因此同一个 EXE 使用不同参数时可分别指定图标。网址、分类和分隔线不支持手动指定图标。

菜单主题在“设置 > 常规”中选择：跟随 Windows、浅色或深色。设置只影响简驭菜单，不会修改系统主题。

## 保存与刷新

点击“应用”会保存并保持设置窗口打开；点击“保存”会保存并关闭窗口；“取消”会放弃尚未应用的更改。简驭会自动监视 `Simpilot.ini` 和 `Simpilot2.ini` 的变化并刷新菜单。读取新配置失败时，程序会保留上一份有效菜单，以避免菜单突然消失。

手动编辑配置文件时，请使用 UTF-8 编码，并在右键托盘菜单的“维护 > 刷新菜单”中进行手动重试。通常更建议通过编辑器修改菜单。
