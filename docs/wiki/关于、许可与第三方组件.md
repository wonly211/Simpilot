# 关于、许可与第三方组件

**简体中文** | [繁體中文](关于、许可与第三方组件.zh-TW) | [English](关于、许可与第三方组件.en-US)

简驭 | Simpilot 是面向 Windows 的轻量级快速启动器和全局热键管理器。它采用便携方式运行：配置、缓存和诊断日志保存在程序目录中，核心功能不需要账户或云端服务。

## 获取帮助与反馈

- [项目主页](https://github.com/wonly211/Simpilot)：源代码、文档和开发动态。
- [最新发布版](https://github.com/wonly211/Simpilot/releases/latest)：下载正式发布包和校验文件。
- [问题反馈](https://github.com/wonly211/Simpilot/issues)：提交可复现的问题、功能建议或翻译建议。

反馈问题时，请提供简驭版本、Windows 版本、复现步骤、预期结果和实际结果。`Log/Simpilot.log` 可帮助定位问题，但提交前应删除用户名、个人路径、文件名和其他敏感信息。

## 第三方组件

Simpilot 使用以下第三方组件：

| 组件 | 用途 |
| --- | --- |
| Everything SDK | 查询 Everything 默认实例的索引数据库。 |
| nlohmann/json | 解析语言资源。 |
| Microsoft PowerToys Keyboard Manager | 提供键盘录制逻辑的可复用基础与参考实现。 |

详细的组件版本、版权声明、复用边界和许可证文本见 [第三方组件声明](https://github.com/wonly211/Simpilot/blob/main/THIRD-PARTY-NOTICES.txt)。Everything 是可选集成：它不可用时，简驭仍可启动，只是搜索窗口和无完整路径程序定位等能力会受影响。
