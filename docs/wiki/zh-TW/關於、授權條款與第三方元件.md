# 關於、授權條款與第三方元件

[简体中文](../zh-CN/关于、许可与第三方组件) | **繁體中文** | [English](../en-US/About-License-and-Third-Party-Components)

简驭 | Simpilot 是適用於 Windows 的輕量級快速啟動器與全域快速鍵管理工具。它採可攜式方式執行：設定、快取與診斷記錄檔均存放在程式目錄中，核心功能不需要帳號或雲端服務。

## 取得協助與回報意見

- [專案首頁](https://github.com/wonly211/Simpilot)：原始碼、文件與開發動態。
- [最新發行版本](https://github.com/wonly211/Simpilot/releases/latest)：下載正式發布包與校驗檔案。
- [問題回報](https://github.com/wonly211/Simpilot/issues)：提交可重現的問題、功能建議或翻譯建議。

回報問題時，請提供简驭版本、Windows 版本、重現步驟、預期結果與實際結果。`Log/Simpilot.log` 有助於診斷問題，但提交前應移除使用者名稱、個人路徑、檔案名稱和其他敏感資訊。

## 第三方元件

Simpilot 使用下列第三方元件：

| 元件 | 用途 |
| --- | --- |
| Everything SDK | 查詢預設 Everything 執行個體的索引資料庫。 |
| nlohmann/json | 解析語言資源。 |
| Microsoft PowerToys Keyboard Manager | 提供快速鍵錄製邏輯可復用的基礎與參考實作。 |

元件版本、著作權聲明、復用邊界與完整授權條款，請參閱[第三方元件聲明](https://github.com/wonly211/Simpilot/blob/main/THIRD-PARTY-NOTICES.txt)。Everything 是選用整合；它無法使用時，简驭仍可啟動，只是 Everything 搜尋與未填寫完整路徑程式的定位等能力會受影響。
