简驭 | Simpilot 是一套適用於 Windows 的輕量級快速啟動器與全域快速鍵管理工具。它以通知區域圖示為入口：可將常用應用程式、資料夾、檔案和網站整理為分層選單，也可透過全域快速鍵直接執行高頻操作。

## 從這裡開始

第一次使用請閱讀[快速開始](快速開始)，完成下載、解壓縮和首次啟動。简驭是可攜式程式，不提供傳統主視窗；啟動後會常駐於 Windows 通知區域。

- 按一下通知區域圖示：開啟快速啟動選單。
- 在通知區域圖示按右鍵：開啟設定、語言、Everything 維護、關於與結束等管理操作。
- 圖示未直接顯示時：請展開 Windows 工作列的隱藏圖示區域。

## 核心能力

- **快速啟動選單**：支援分類、分隔線，以及應用程式、資料夾、檔案和網址啟動項目。
- **全域快速鍵**：可快速開啟選單、設定視窗、Everything，或執行自訂動作。
- **Windows 快速鍵封鎖**：在简驭執行期間即時攔截選定的 `Win+字母` 組合；不修改 Windows 系統原則，結束简驭後自動恢復。
- **Everything 整合**：可開啟或還原 Everything，並協助定位未填寫完整路徑的程式。
- **本地化**：簡體中文、繁體中文和英文已內建於程式；選用的 `Language.lng` 可提供其他介面語言。
