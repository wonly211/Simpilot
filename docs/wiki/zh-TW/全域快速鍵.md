# 全域快速鍵

[简体中文](../zh-CN/全局热键) | **繁體中文** | [English](../en-US/Global-Hotkeys)

全域快速鍵可在简驭於背景執行時，從其他一般桌面程式直接觸發操作。開啟「設定 > 全域快速鍵」即可檢視、錄製、啟用或暫停快速鍵。

## 內建快速鍵

简驭提供以下內建功能，每項都可分別錄製快速鍵、清除快速鍵，並使用開關啟用或停用：

| 內建功能 | 作用 |
| --- | --- |
| 快速啟動選單 | 開啟主快速啟動選單。 |
| 第二選單 | 開啟選用的第二選單。 |
| 設定 | 開啟简驭設定視窗。 |
| Everything 搜尋 | 開啟或還原 Everything 搜尋視窗。 |

未設定快速鍵或關閉啟用開關的功能不會回應組合鍵。Everything 元件無法使用時，简驭仍可正常執行，但「Everything 搜尋」快速鍵可能無法完成操作。

## 建立自訂快速鍵

在「自訂全域快速鍵」區域選擇「新增」，依下列方式建立操作：

1. 選擇動作類型：**開啟應用程式**、**開啟資料夾**或**開啟檔案**。
2. 填寫或選擇目標路徑；開啟應用程式時可額外設定參數、工作目錄、系統管理員權限、重複啟動策略和初始視窗狀態。
3. 按一下錄製快速鍵控制項，再按下所需組合鍵。
4. 確認啟用開關處於開啟狀態，然後按一下「套用」或「儲存」。

建立後可在清單中編輯、刪除或暫時停用該快速鍵。與快速啟動選單不同，自訂全域快速鍵不支援直接開啟網址；需要開啟網站時，請將網址加入[快速啟動選單](快速啟動選單)。

## 錄製快速鍵

按一下錄製快速鍵控制項後，简驭會進入短暫的按鍵記錄狀態。此時直接按下所需組合鍵，錄製結束後輸入框會顯示結果；按 `Esc` 會取消本次錄製。錄製期間，简驭會暫時處理按鍵事件，避免已支援的組合鍵同時觸發一般應用程式操作。

錄製快速鍵不代表一定能註冊成功。按一下「套用」或「儲存」時，简驭會檢查組合鍵是否已被其他简驭快速鍵、Windows 或其他程式占用，並在需要覆寫既有简驭設定時要求確認。

## 與 Windows 快速鍵封鎖的連動

在「設定 > Windows 快速鍵封鎖」中，可選擇受支援的 `Win+A` 至 `Win+Z` 組合。此功能只在简驭執行時即時攔截鍵盤事件：不會修改 Windows 系統原則，也不會關閉 Game Bar、意見反應中樞等 Windows 功能；結束简驭後會自動恢復。

如果啟用的內建或自訂快速鍵剛好使用精確的 `Win+字母` 組合，简驭會自動連動並鎖定對應的封鎖項目，使 Windows 不會先執行原有操作，而是轉由简驭執行設定動作。停用、清除或刪除最後一個使用該組合的全域快速鍵後，此連動鎖定會解除；你原先手動選擇的封鎖狀態仍會保留。

封鎖只比對精確的 `Win+字母`。例如封鎖 `Win+Z` 不會影響 `Shift+Win+Z`、`Ctrl+Win+Z` 或 `Alt+Win+Z`。

## 限制與建議

- `Win+L` 是 Windows 安全性鎖定快速鍵，不能由简驭封鎖或設為全域快速鍵。
- `Ctrl+Alt+Del` 等安全桌面組合不受一般桌面應用程式控制。
- 登入畫面、其他使用者工作階段及部分遠端桌面環境不在快速鍵封鎖的保證範圍內。
- 若某個組合已被其他程式註冊，請選擇不衝突的組合；不要覆寫不了解用途的快速鍵。
- 設定變更後應按一下「套用」或「儲存」，再測試實際行為。
