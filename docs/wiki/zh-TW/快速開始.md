# 快速開始

[简体中文](../zh-CN/快速开始) | **繁體中文** | [English](../en-US/Quick-Start)

本頁可協助你在幾分鐘內執行简驭 | Simpilot，並開啟第一個快速啟動選單。

## 系統需求

- Windows 10 或 Windows 11。
- x64 處理器和作業系統。
- 目前使用者具有寫入權限的固定程式目錄。

## 下載與解壓縮

1. 從 [GitHub Releases](https://github.com/wonly211/Simpilot/releases/latest) 下載最新的 `Simpilot-*-win-x64.zip`。
2. 將壓縮檔**完整解壓縮**到固定目錄，例如個人軟體目錄或資料磁碟目錄。
3. 保持 `Simpilot.exe` 與 `Everything/` 目錄的相對位置，不要只複製主程式檔案。
4. 按兩下執行 `Simpilot.exe`。

發佈套件另附 `.sha256` 驗證檔。需要確認下載完整性時，可在 PowerShell 中執行：

```powershell
Get-FileHash .\Simpilot-*-win-x64.zip -Algorithm SHA256
```

將結果與同名 `.sha256` 檔中的值比較。目前發佈套件未進行數位簽署；首次執行若遇到 Windows SmartScreen 提示，請先確認檔案來自本專案正式 Release，並完成驗證。

## 目錄結構

简驭採可攜方式發佈。首次執行後，設定、快取和記錄檔會保存在程式目錄內：

```text
Simpilot.exe
Language.lng                 # 選用的額外語言包
Everything/
  Everything.exe
  Everything64.dll
Config/
  Simpilot.ini
  Simpilot2.ini              # 依需要建立的第二選單
  Setting.ini
Cache/
  RunIcon/
Log/
  Simpilot.log
```

`Language.lng` 不存在時會被忽略，简驭仍可使用內建的簡體中文、繁體中文與英文正常啟動。請不要刪除或移動 `Everything/`，否則 Everything 搜尋和依賴其定位的功能可能無法使用，但简驭本身仍可啟動。

## 第一次啟動

简驭啟動後不會顯示傳統主視窗，而會在 Windows 通知區域建立圖示。找不到圖示時，請檢查工作列右側的隱藏圖示區域。

- **按一下**圖示，開啟快速啟動選單。
- 在圖示上**按右鍵**，開啟設定和維護選單。
- 預設可用反引號鍵（通常位於 `Esc` 下方、數字 `1` 左側）開啟快速啟動選單。

首次執行時，简驭會建立包含範例啟動項目的 `Config/Simpilot.ini`。你可直接使用範例，也可以在「設定 > 快速啟動選單」中編輯自己的選單。

## 建議的下一步

1. 閱讀[快速啟動選單](快速啟動選單)，整理常用應用程式、資料夾與檔案。
2. 閱讀[全域快速鍵](全域快速鍵)，為常用操作錄製組合鍵。
3. 在「設定 > 一般」中選擇介面語言、選單佈景主題，或設定登入 Windows 後自動啟動。
