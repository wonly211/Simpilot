# 翻譯與貢獻

[简体中文](../zh-CN/翻译与贡献) | **繁體中文** | [English](../en-US/Translating-and-Contributing)

感謝你協助简驭 | Simpilot 支援更多語言。程式內建簡體中文、繁體中文和 English；其他語言透過 `Language.lng` 提供。

## 提交問題與建議

功能建議、缺陷回報和翻譯問題請提交到 [GitHub Issues](https://github.com/wonly211/Simpilot/issues)。請提供简驭版本、Windows 版本、清楚的重現步驟和預期結果。涉及記錄檔時，請先移除個人目錄、使用者名稱和敏感檔案名稱。

## 建立翻譯原始檔

1. 以儲存庫中的 `Languages/en-US.json` 為範本建立語言檔案，例如 `fr-FR.json`。
2. 使用 UTF-8 編碼儲存，並保留全部字串鍵。
3. 填寫語言代碼、語言自稱和每段介面文字。

最小結構如下：

```json
{
  "locale": "fr-FR",
  "name": "Francais",
  "strings": {
    "ui.settings": "Parametres"
  }
}
```

- `locale` 使用類似 `fr-FR` 的語言和區域代碼。
- `name` 是設定頁中顯示的語言自稱，應使用該語言本身的文字。
- `strings` 必須以 `Languages/en-US.json` 的完整鍵集為基準。漏掉的鍵會回退到 English，但不應作為正式翻譯發佈。

請不要翻譯品牌名「简驭 | Simpilot」、產品檔名、設定檔名、命令列參數或程式碼鍵名。

## 產生 Language.lng

儲存庫提供建置期工具 `tools/language_pack_builder.cpp`。先在 Windows 的 CMake 建置目錄產生該工具：

```powershell
cmake -S . -B build/vs2022-x64 -G "Visual Studio 17 2022" -A x64
cmake --build build/vs2022-x64 --config Release --target simpilot_language_pack_builder
```

再使用工具打包 JSON 原始檔：

```powershell
.\build\vs2022-x64\Release\simpilot_language_pack_builder.exe `
  .\Language.lng .\fr-FR.json
```

可一次加入多份翻譯原始檔：

```powershell
.\build\vs2022-x64\Release\simpilot_language_pack_builder.exe `
  .\Language.lng .\fr-FR.json .\de-DE.json
```

產生的 `Language.lng` 是壓縮二進位檔。將它放到 `Simpilot.exe` 同目錄，重新啟動简驭後即可在「設定 > 一般 > 顯示語言」中選擇新語言。

## 驗證清單

提交前請確認：

- 應用程式啟動、通知區域選單、設定、編輯器和對話方塊沒有明顯的英文殘留；
- 文字在常見顯示縮放下不截斷，按鈕文字不重疊；
- 快速鍵、檔名、變數和格式化預留位置保持原樣；
- `Language.lng` 放在程式同目錄後能顯示目標語言；
- 移走或損壞 `Language.lng` 後，简驭仍能正常啟動並使用內建語言。

## 提交翻譯

建議將 JSON 原始檔和必要說明一併提交到儲存庫，而不是只提交二進位 `Language.lng`。維護者會複核鍵完整性、術語一致性、介面顯示和打包結果，再將語言包隨相應發佈版本提供。
