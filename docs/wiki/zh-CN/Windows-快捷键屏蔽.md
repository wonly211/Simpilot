# Windows 快捷键屏蔽

**简体中文** | [English](../en-US/Windows-Hotkey-Blocking)

“设置 > Windows 快捷键屏蔽”用于选择需要由简驭实时拦截的受支持 `Win+字母` 组合。

## 工作方式

- 屏蔽只在简驭运行期间有效；退出简驭后立即恢复 Windows 原有行为。
- 简驭拦截键盘事件，不修改 Windows 策略、注册表或系统功能。
- 无需重启 Windows 资源管理器。
- 每个组合使用独立滑动开关；修改后点击“应用”或“保存”。

例如，屏蔽 `Win+Z` 不会影响 `Shift+Win+Z`、`Ctrl+Win+Z` 或 `Alt+Win+Z`。

## 与全局热键的联动

当启用的内置或自定义热键使用精确的 `Win+字母` 时，简驭自动屏蔽对应 Windows 快捷键，并优先执行该热键动作。设置页会显示该项已由全局热键启用。

停用、清除或删除最后一个使用该组合的全局热键后，自动联动解除；用户此前手动设置的屏蔽状态仍会保留。

## 限制

- `Win+L` 是 Windows 安全锁定快捷键，不提供屏蔽或全局热键设置。
- `Ctrl+Alt+Del` 等安全桌面组合不能由普通桌面程序截获。
- 登录界面、其他用户会话、权限更高的桌面和部分远程桌面环境不在保证范围内。
