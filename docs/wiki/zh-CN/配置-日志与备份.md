# 配置、日志与备份

**简体中文** | [繁體中文](../zh-TW/設定、記錄檔與備份) | [English](../en-US/Configuration-Logs-and-Backup)

简驭 | Simpilot 是便携式程序。运行数据保存在程序目录中，便于备份、迁移和排查问题。请将完整发布包解压到当前 Windows 用户可写入的固定目录后再运行。

## 文件与目录

```text
Config/
  Simpilot.ini
  Simpilot2.ini
  Setting.ini
Cache/
  program-cache.tsv
  RunIcon/
Log/
  Simpilot.log
```

| 位置 | 用途 | 可以删除吗 |
| --- | --- | --- |
| `Config/Simpilot.ini` | 主快捷启动菜单 | 不建议；删除后会丢失主菜单内容 |
| `Config/Simpilot2.ini` | 可选的第二快捷启动菜单 | 可以；不再需要第二菜单时删除 |
| `Config/Setting.ini` | 语言、主题、开机启动、热键和 Windows 快捷键屏蔽 | 不建议；删除后相关设置恢复默认 |
| `Cache/program-cache.tsv` | 无完整路径程序的已确认位置 | 可以；下次需要时重新查找 |
| `Cache/RunIcon/` | 自动图标与人工指定图标 | 可以；会丢失人工图标并重新生成自动图标 |
| `Log/Simpilot.log` | 启动、菜单、Everything、热键和错误诊断 | 可以；只会丢失历史诊断信息 |

菜单配置与 `Setting.ini` 统一使用 UTF-8。日常修改应优先通过设置窗口完成；手工编辑菜单时请使用 UTF-8 文本编辑器。

## 日志保留规则

简驭只使用一个日志文件：`Log/Simpilot.log`。每次启动时，会清理其中超过 90 天的带时间戳记录；不会创建按日期轮换的额外日志文件。

日志可能包含程序路径、文件名和错误信息。向他人提交日志前，请先检查并删除不希望公开的个人路径或文件名。

## 备份与迁移

最稳妥的备份方法是：

1. 从托盘右键菜单选择“退出”。
2. 复制整个 Simpilot 程序目录到备份位置。
3. 恢复时，先完整解压相同或更新的发布包，再将备份中的 `Config/` 覆盖回去。

若只备份必要数据，请至少保留 `Config/`；使用过人工指定菜单图标时，还要保留 `Cache/RunIcon/`。`program-cache.tsv` 和日志不影响设置本身，可不备份。

## 更新注意事项

更新前先退出简驭，再解压新版本并覆盖程序文件。配置不需要自动迁移；请继续使用当前名称：`Config/Setting.ini`。旧文件名不会被自动读取。

移动整个程序目录后，如已开启“登录 Windows 后自动启动”，请重新打开“设置 > 常规”，应用一次该选项，使开机启动位置更新为新路径。
