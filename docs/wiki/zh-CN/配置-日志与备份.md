# 配置、日志与备份

**简体中文** | [English](../en-US/Configuration-Logs-and-Backup)

简驭 | Simpilot 是便携式程序。运行数据保存在程序目录中，便于备份、迁移和排查问题。请将完整发布包解压到当前 Windows 用户可写入的固定目录后再运行。

## 文件与目录

```text
Config/
  Simpilot.ini
  Simpilot2.ini
  Setting.ini
Cache/
  program-cache.tsv
  RunIcon/
Log/
  Simpilot.log
```

| 位置 | 用途 | 可以删除吗 |
| --- | --- | --- |
| `Config/Simpilot.ini` | 主快捷启动菜单 | 不建议；删除后会丢失主菜单内容 |
| `Config/Simpilot2.ini` | 可选的第二快捷启动菜单 | 可以；不再需要第二菜单时删除 |
| `Config/Setting.ini` | 语言、主题、开机启动、热键、键盘映射和 Windows 快捷键屏蔽 | 不建议；删除后相关设置恢复默认 |
| `Cache/program-cache.tsv` | 无完整路径程序的已确认位置 | 可以；下次需要时重新查找 |
| `Cache/RunIcon/` | 自动图标与人工指定图标 | 可以；会丢失人工图标并重新生成自动图标 |
| `Log/Simpilot.log` | 启动、菜单、Everything、热键和错误诊断 | 可以；只会丢失历史诊断信息 |

菜单配置与 `Setting.ini` 统一使用 UTF-8。日常修改应优先通过设置窗口完成；手工编辑菜单时请使用 UTF-8 文本编辑器。

键盘映射保存在 `Setting.ini` 的 `[KeyboardMappings]` 节。旧配置没有该节时不会生成
任何映射，也不会改变现有热键。加载时单条无效映射会被跳过并写入日志，其他设置继续
生效；通过设置窗口保存前会整体校验规则。

## 日志保留规则

简驭只使用一个日志文件：`Log/Simpilot.log`。每次启动时，会清理其中超过 90 天的带时间戳记录；不会创建按日期轮换的额外日志文件。

日志可能包含程序路径、文件名和错误信息。向他人提交日志前，请先检查并删除不希望公开的个人路径或文件名。

## 备份与迁移

最稳妥的备份方法是：

1. 从托盘右键菜单选择“退出”。
2. 复制整个 Simpilot 程序目录到备份位置。
3. 恢复时，先完整解压相同或更新的发布包，再将备份中的 `Config/` 覆盖回去。

若只备份必要数据，请至少保留 `Config/`；使用过人工指定菜单图标时，还要保留 `Cache/RunIcon/`。`program-cache.tsv` 和日志不影响设置本身，可不备份。

## 更新注意事项

更新前先退出简驭，再解压新版本并覆盖程序文件。配置不需要自动迁移；请继续使用当前名称：`Config/Setting.ini`。旧文件名不会被自动读取。

移动整个程序目录后，如已开启“登录 Windows 后自动启动”，请重新打开“设置 > 常规”，应用一次该选项，使开机启动位置更新为新路径。

### 全局备份、恢复与旧版迁入

在“设置 > 常规 > 配置备份与迁移”查看当前配置目录，选择“导出全部设置”“导入备份”或“从旧版目录迁入”。备份文件扩展名为 `.simpilot-backup`，包含各模块已保存设置、主菜单和第二菜单、菜单图标、输入法记忆、程序选择记录以及外部语言文件。存在未应用修改时，可选择先应用或仅导出已保存状态。

导入采用整包恢复，确认后替换当前配置；备份中没有的第二菜单等受管理文件也会移除。恢复前会自动备份当前配置到程序目录的 `Backups/`，随后重启加载。恢复失败会回滚；中途退出后，下次启动会处理未完成的恢复。备份格式、校验或规则无效时不会静默跳过后继续导入。自动备份会保留，用户可自行整理。

首次在没有配置的目录启动时，可选择全新使用、从旧版目录迁入或导入备份。v1.0.8、v1.0.9、v1.0.10 用户无需先安装带有导出按钮的版本，直接选择旧程序目录即可迁入，旧目录保持不变。其他版本按实际文件格式校验。

便携模式仍按程序目录保存设置；原目录更新程序可沿用配置，新目录解压不会自动寻找旧目录。读取现有配置失败时，程序会保留原文件并提示修复或恢复，不用默认设置覆盖它。

备份不包含程序本体、Everything 组件、日志和菜单指向的外部应用或脚本。跨目录、跨电脑恢复后，应检查相对路径、失效的应用路径及未安装的输入法；这些项目不会自动安装或下载。当前备份格式最多支持 128 MiB 数据、8192 个文件。
