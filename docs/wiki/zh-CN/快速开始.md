# 快速开始

**简体中文** | [繁體中文](../zh-TW/快速開始) | [English](../en-US/Quick-Start)

本页帮助你在几分钟内运行简驭 | Simpilot，并打开第一个快捷启动菜单。

## 系统要求

- Windows 10 或 Windows 11。
- x64 处理器和操作系统。
- 当前用户具有写入权限的固定程序目录。

## 下载与解压

1. 从 [GitHub Releases](https://github.com/wonly211/Simpilot/releases/latest) 下载最新的 `Simpilot-*-win-x64.zip`。
2. 将压缩包**完整解压**到固定目录，例如个人软件目录或数据盘目录。
3. 保持 `Simpilot.exe` 与 `Everything/` 目录的相对位置，不要只复制主程序文件。
4. 双击运行 `Simpilot.exe`。

发布包还附有 `.sha256` 校验文件。需要确认下载完整性时，可在 PowerShell 中运行：

```powershell
Get-FileHash .\Simpilot-*-win-x64.zip -Algorithm SHA256
```

将结果与同名 `.sha256` 文件中的值比较。当前发布包未进行数字签名；首次运行若遇到 Windows SmartScreen 提示，请先确认文件来自本仓库的正式 Release 并完成校验。

## 目录结构

简驭采用便携方式发布。首次运行后，配置、缓存和日志会保存在程序目录内：

```text
Simpilot.exe
Language.lng                 # 可选的额外语言包
Everything/
  Everything.exe
  Everything64.dll
Config/
  Simpilot.ini
  Simpilot2.ini              # 按需创建的第二菜单
  Setting.ini
Cache/
  RunIcon/
Log/
  Simpilot.log
```

`Language.lng` 不存在时会被忽略，简驭仍可使用内置的简体中文、繁体中文和英文正常启动。请不要删除或移动 `Everything/`，否则 Everything 搜索和依赖其定位的功能可能不可用，但简驭本身仍可启动。

## 第一次启动

简驭启动后不会显示传统主窗口，而会在 Windows 通知区域创建托盘图标。找不到图标时，请检查任务栏右侧的隐藏图标区域。

- **左键单击**图标，打开快捷启动菜单。
- **右键单击**图标，打开设置和维护菜单。
- 默认可用反引号键（通常位于 `Esc` 下方、数字 `1` 左侧）打开快捷启动菜单。

首次运行时，简驭会创建 `Config/Simpilot.ini`，其中带有示例启动项。你可以直接使用示例，也可以在“设置 > 快捷启动菜单”中编辑自己的菜单。

## 建议的下一步

1. 阅读[快捷启动菜单](快捷启动菜单)，整理常用应用、文件夹和文件。
2. 阅读[全局热键](全局热键)，为常用操作录制组合键。
3. 在“设置 > 常规”中选择界面语言、菜单主题，或设置登录 Windows 后自动启动。
