# 常见问题与故障排查

**简体中文** | [English](../en-US/FAQ-and-Troubleshooting)

## 启动后没有主窗口

这是正常行为。简驭 | Simpilot 常驻在 Windows 通知区域，不显示普通主窗口。

1. 查看任务栏右侧的通知区域及“隐藏的图标”。
2. 左键托盘图标打开快捷启动菜单；右键打开设置和维护菜单。
3. 若完全找不到图标，确认已经完整解压发布包、程序目录可写，并查看 `Log/Simpilot.log`。

## 托盘图标消失

Windows 资源管理器重启后，简驭会尝试自动重新注册托盘图标。请稍候片刻；仍未出现时退出并重新启动 `Simpilot.exe`，再查看日志。

## 快捷启动菜单缺少项目

简驭会隐藏不存在或无法解析的目标。请检查：

- 目标路径是否存在；
- 相对路径是否相对于 `Config/` 填写正确；
- 程序名是否能在 Windows 常规搜索路径、`PATH` 或 Everything 中找到；
- 菜单文件是否为有效 UTF-8。

修正后可等待自动刷新，或右键托盘图标选择“维护 > 刷新菜单”。配置读取失败时，简驭会保留上一份有效菜单。

## 全局热键没有响应

1. 在“设置 > 全局热键”确认热键已录制且开关已启用。
2. 点击“应用”或“保存”。
3. 关闭设置窗口后再测试。
4. 检查是否和其他程序或 Windows 快捷键冲突。
5. 改用未被系统保留的组合，并查看 `Log/Simpilot.log` 中的热键注册错误。

`Win+L`、`Ctrl+Alt+Del` 等 Windows 安全组合不能作为简驭热键，也不能由普通桌面程序屏蔽。

## Windows 快捷键仍会执行

在“设置 > Windows 快捷键屏蔽”中打开对应 `Win+字母` 开关，并点击“应用”或“保存”。该功能只屏蔽精确组合，例如屏蔽 `Win+Z` 不会影响 `Shift+Win+Z`。

屏蔽只在简驭运行期间生效，退出后自动恢复，不需要重启 Windows 资源管理器。登录界面、其他用户会话、安全桌面和部分远程桌面环境不在保证范围内。

## Everything 搜索打不开或无法定位程序

1. 确认 `Everything/Everything.exe` 和 `Everything/Everything64.dll` 都存在。
2. 右键托盘图标，选择“维护 > 打开 Everything”。
3. 若需要索引服务，选择“维护 > 安装/修复 Everything 服务...”，并在权限确认窗口中允许操作。
4. 如您仅使用命名 Everything 实例，请启动默认实例，或使用随包 Everything。

Everything 不可用不会阻止简驭启动，只会影响 Everything 搜索和无完整路径程序的定位。更多规则见 [Everything 集成](Everything-集成)。

## 设置的语言没有出现

简体中文、繁體中文和 English 已内建。其他语言需要把 `Language.lng` 放在 `Simpilot.exe` 同目录，然后重启简驭。

若仍未出现，通常是语言包文件名、位置或格式不正确。删除或移走有问题的 `Language.lng` 后，简驭会正常回退到内建语言。详见[语言与 Language.lng](语言与-Language.lng)。

## 菜单图标不正确或没有更新

在“设置 > 菜单图标”中重新选择图标或恢复自动图标。自动图标和人工图标都保存在 `Cache/RunIcon/`。删除该目录可以重建图标缓存，但会同时删除人工指定图标。

## 反馈问题时应提供什么

请在 [GitHub Issues](https://github.com/wonly211/Simpilot/issues) 中描述：Windows 版本、简驭版本、复现步骤、预期结果、实际结果，以及相关日志片段。请先清理日志中的个人路径、用户名和敏感文件名。
