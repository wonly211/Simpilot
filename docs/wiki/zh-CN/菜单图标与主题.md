# 菜单图标与主题

**简体中文** | [English](../en-US/Menu-Icons-and-Themes)

在“设置 > 菜单图标”中可以检查快捷启动项的图标来源，并为单个启动项手动指定图标。

## 自动图标

简驭会从应用、文件夹或文件的系统图标中提取图像，并在 `Cache/RunIcon/` 中生成透明的 128x128 ICO 缓存。菜单使用缓存图标，因此重复打开菜单不会反复访问原始文件。

目录使用系统文件夹图标；文件与应用优先使用其关联图标；EXE、DLL 和 ICO 可作为人工图标来源。

## 人工指定图标

1. 选择对应菜单项。
2. 点击“选择图标”。
3. 选择 ICO、EXE 或 DLL，并在需要时选择其中的图标序号。
4. 点击“应用”或“保存”。

同一个 EXE 即使以不同参数、不同路径或不同 `explorer.exe shell:::{GUID}` 方式启动，也可以分别指定图标。选择“恢复自动图标”可移除当前人工指定。

删除 `Cache/RunIcon/` 会重建自动缓存，也会删除人工指定图标；备份人工图标时请保留该目录。

## 主题

快捷启动菜单和托盘右键菜单可选择“跟随 Windows”“浅色”或“深色”。设置窗口与相关编辑窗口始终使用独立浅色界面，不受菜单主题影响。
