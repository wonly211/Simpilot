# 選單圖示與佈景主題

[简体中文](菜单图标与主题) | **繁體中文** | [English](菜单图标与主题.en-US)

在「設定 > 選單圖示」中可以檢查快速啟動項目的圖示來源，並為單一啟動項目手動指定圖示。

## 自動圖示

简驭會從應用程式、資料夾或檔案的系統圖示中擷取影像，並在 `Cache/RunIcon/` 中產生透明的 128x128 ICO 快取。選單使用快取圖示，因此重複開啟選單時不必反覆存取原始檔案。

目錄使用系統資料夾圖示；檔案與應用程式優先使用其關聯圖示；EXE、DLL 和 ICO 可作為人工圖示來源。

## 人工指定圖示

1. 選擇對應選單項目。
2. 按一下「選擇圖示」。
3. 選擇 ICO、EXE 或 DLL，並在需要時選擇其中的圖示序號。
4. 按一下「套用」或「儲存」。

同一個 EXE 即使以不同參數、不同路徑或不同 `explorer.exe shell:::{GUID}` 方式啟動，也可分別指定圖示。選擇「還原自動圖示」可移除目前人工指定的圖示。

刪除 `Cache/RunIcon/` 會重建自動快取，也會刪除人工指定圖示；備份人工圖示時請保留此目錄。

## 佈景主題

快速啟動選單與通知區域右鍵選單可選擇「跟隨 Windows」「淺色」或「深色」。設定視窗與相關編輯視窗一律使用獨立淺色介面，不受選單佈景主題影響。

相關頁面：[快速啟動選單](快捷启动菜单.zh-TW)、[設定、記錄檔與備份](配置-日志与备份.zh-TW)。
