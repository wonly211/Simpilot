# 設定、記錄檔與備份

[简体中文](配置-日志与备份) | **繁體中文** | [English](Configuration-Logs-and-Backup)

简驭 | Simpilot 是可攜式程式。執行資料儲存在程式目錄中，便於備份、移轉和排查問題。請將完整發佈套件解壓縮到目前 Windows 使用者可寫入的固定目錄後再執行。

## 檔案與目錄

```text
Config/
  Simpilot.ini
  Simpilot2.ini
  Setting.ini
Cache/
  program-cache.tsv
  RunIcon/
Log/
  Simpilot.log
```

| 位置 | 用途 | 可以刪除嗎 |
| --- | --- | --- |
| `Config/Simpilot.ini` | 主快速啟動選單 | 不建議；刪除後會遺失主選單內容 |
| `Config/Simpilot2.ini` | 選用的第二快速啟動選單 | 可以；不再需要第二選單時刪除 |
| `Config/Setting.ini` | 語言、佈景主題、開機啟動、快速鍵和 Windows 快速鍵封鎖 | 不建議；刪除後相關設定會恢復預設值 |
| `Cache/program-cache.tsv` | 無完整路徑程式的已確認位置 | 可以；下次需要時會重新查找 |
| `Cache/RunIcon/` | 自動圖示與人工指定圖示 | 可以；會遺失人工圖示並重新產生自動圖示 |
| `Log/Simpilot.log` | 啟動、選單、Everything、快速鍵和錯誤診斷 | 可以；只會遺失歷史診斷資訊 |

選單設定與 `Setting.ini` 一律使用 UTF-8。日常修改應優先透過設定視窗完成；手動編輯選單時請使用 UTF-8 文字編輯器。

## 記錄檔保留規則

简驭只使用一個記錄檔：`Log/Simpilot.log`。每次啟動時，會清理其中超過 90 天的帶時間戳記錄；不會建立按日期輪替的額外記錄檔。

記錄檔可能包含程式路徑、檔案名稱和錯誤資訊。向他人提交記錄檔前，請先檢查並移除不希望公開的個人路徑或檔案名稱。

## 備份與移轉

最穩妥的備份方式如下：

1. 從通知區域右鍵選單選擇「結束」。
2. 複製整個 Simpilot 程式目錄到備份位置。
3. 復原時，先完整解壓縮相同或更新的發佈套件，再將備份中的 `Config/` 覆蓋回去。

若只備份必要資料，請至少保留 `Config/`；使用過人工指定選單圖示時，還要保留 `Cache/RunIcon/`。`program-cache.tsv` 和記錄檔不影響設定本身，可不備份。

## 更新注意事項

更新前請先結束简驭，再解壓縮新版本並覆蓋程式檔案。設定不需要自動移轉；請繼續使用目前名稱：`Config/Setting.ini`。舊檔名不會被自動讀取。

移動整個程式目錄後，如已開啟「登入 Windows 後自動啟動」，請重新開啟「設定 > 一般」，套用一次該選項，使開機啟動位置更新為新路徑。
