# 语言与 Language.lng

**简体中文** | [繁體中文](语言与-Language.lng.zh-TW) | [English](语言与-Language.lng.en-US)

简驭 | Simpilot 内建简体中文、繁体中文与 English。首次运行以及语言设置无效时，默认使用简体中文。

内建语言已经以压缩资源形式存入 `Simpilot.exe`，发布目录不需要 `Languages` 文件夹。删除、移动或损坏可选外部语言包都不会影响三种内建语言，也不会阻止程序启动。

## 切换内建语言

1. 右键单击托盘图标，选择“设置...”。
2. 打开“常规”。
3. 在“显示语言”中选择简体中文、繁體中文或 English。

选择后界面立即切换，无需重启简驭。设置会保存到 `Config/Setting.ini`。快捷启动菜单标题、分类名称和路径属于用户数据，不会自动翻译。

## 使用其他语言

其他语言通过可选文件 `Language.lng` 提供。将它放在 `Simpilot.exe` 同一目录：

```text
Simpilot.exe
Language.lng
Everything/
Config/
```

重新启动简驭后，包内语言会出现在“设置 > 常规 > 显示语言”中。一个 `Language.lng` 可以包含一种或多种额外语言。

若 `Language.lng` 不存在、格式错误、版本不兼容或无法解压，简驭会直接忽略该文件并继续使用内建语言。外部语言包只能增加语言，不能替换简体中文、繁体中文或 English。

## 文件格式

`Language.lng` 是压缩的二进制语言包，不是可直接编辑的文本文件。它使用固定文件头和 XPRESS Huffman 压缩负载，目的是避免在发布目录中直接暴露 JSON 文本，并减小资源体积。

这不是加密或安全措施。需要修改翻译时，应编辑 JSON 源文件后重新打包，而不是尝试修改 `.lng` 文件。

## 翻译缺失时的显示

每一条界面文本按以下顺序取得：

```text
所选语言 -> 内建 English -> [missing translation]
```

因此，外部语言包即使漏掉少量字符串，界面也不会出现空白控件；但正式发布前仍应补齐所有翻译项。

如何制作与发布新语言，请参阅[翻译与贡献](翻译与贡献)。
