# Simpilot 统一视觉基线

版本：设计基线 1，2026-09-27 定稿；原生采集日期为 2026-09-26。状态：设计交付，不是产品版本。

本文件为选定规范；两份独立审计中的候选尺寸与本文件冲突时，以本文件为准。图片证据与验证边界见 [审计报告](AUDIT.md)；离线效果图不是正式 UI。保持 Win32、静态模块贡献、现有保存语义和现有 Logo，不增加全局主题功能。

## 1. 设计原则

- 优美：相关内容共享起点，标签、值和操作形成稳定阅读顺序。
- 精致：以统一文字、控件尺寸、对齐和状态表达实现，不靠缩小文字。
- 克制：不用装饰卡片、渐变、插画背景或无功能图标；不填充低密度页的自然空白。
- 典雅：来自比例和留白，不引入仿古装饰；Logo 红色只用于品牌，不扩展为界面底色。
- 设置页、编辑器、弹窗、菜单共享组件语言，但使用不同任务网格。

## 2. 度量与 DPI

下列尺寸均为 DIP。原生物理像素采用 `MulDiv(dip, dpi, 96)`；相邻边界从同一个已换算锚点推导，不能逐项累加舍入误差。字号和布局不随窗口宽度缩放。

| DIP | 100% / 96 DPI | 150% / 144 DPI | 200% / 192 DPI |
| --- | --- | --- | --- |
| 4 | 4 px | 6 px | 8 px |
| 16 | 16 px | 24 px | 32 px |
| 20 | 20 px | 30 px | 40 px |
| 28 | 28 px | 42 px | 56 px |
| 32 | 32 px | 48 px | 64 px |
| 36 | 36 px | 54 px | 72 px |
| 40 | 40 px | 60 px | 80 px |

1 DIP 细线同样换算，150% 时为 2 物理像素。焦点框 2 DIP，不用半像素 GDI 绘制。

效果图设置画布 1028×714，包括用于比较的 30 DIP 模拟标题栏；设计客户区为 1028×684。最小提案客户区 960×684。映射默认画布 963×651、最小 900×640，同样扣除 30 DIP 模拟标题栏。原生非客户区由 Windows 决定，不能把模拟标题栏尺寸写死到 Win32；实施时用客户区约束计算外框。现有窗口最小值不因本规范立即变化，原生最小尺寸验证尚未完成。

这些是选定设计值，不是从 JPEG 取色。原生字体渲染和高对比度可读性需后续测量，不能把本表当作已完成无障碍验收。

## 4. 字体与图标

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 页及主弹窗标题 | 24 / 32 | 600 |
| 品牌名称 | 16 / 22 | 600 |
| 分组标题 | 14 / 20 | 600 |
| 正文、按钮、输入、菜单 | 14 / 20 | 400 |
| 列头、辅助状态 | 12 / 18 | 600 / 400 |

快捷启动菜单是任务型例外：文字 15 DIP、正常字重，用户项目图标 24×24 DIP；行高与宽度见第 6.D 节。设置窗口、列表工具栏和托盘菜单不随此例外调整。

英文字体 Segoe UI；中文回退 Microsoft YaHei UI；字距 0。不对汉字做强制拉伸。原生实现的 `LOGFONT` 高度从 DIP 一次换算，不把 DIP 直接当 point。长标题换行并推开正文；页正文可滚动，不能覆盖底栏。

品牌区现有 Logo 32×32，名称间距 12；关于页 Logo 56×56。功能图标 16×16，线宽 1.5 DIP，图标与文字间距 8。沿用既有原生图标或产品图标；离线提案使用附许可证的 Lucide 图标，不要求生产引入浏览器依赖。用户配置的菜单图标不替换成统一品牌图标。

添加、编辑、删除使用加号、铅笔、垃圾桶；排序用上下箭头，层级用缩进图标；清除用 ×。图标按钮须有对应对象的辅助名称，鼠标悬停 500 ms 显示工具提示，键盘焦点也提供名称。工具提示不能作为错误信息的唯一载体。

## 5. 外壳

| 项目 | 选定值 |
| --- | --- |
| 导航 | 宽 216；左右内缩 12；条目高 44，间隔 4；文字左内缩 16 |
| 导航选中 | `selection` 底，左侧 3×16 指示线 |
| 导航长文本 | 最多两行，每行 20；超出两行时条目增高到 64，其后条目顺移 |
| 内容 | 左右边距 28；顶部 28；标题后间距 24 |
| 底栏 | 高 72；顶部 1 分隔线；左右内边距 28 |
| 底栏命令 | 取消、应用、保存，右对齐；各 88×36；间隔 8 |
| 底栏状态 | 左侧，14/20；与按钮区域至少 24 间隔；长错误可换两行 |

保存是唯一实心主操作；应用为中性描边；取消为低强调但相同命中高度。状态文本不进入按钮区域，超过两行的错误由既有错误界面完整呈现，底栏显示简短摘要，不能隐藏失败。

导航、页正文和底栏分离；页内容不能伸入底栏。窗口变高时，新增空间给列表或正文滚动区域，不扩大标题、普通表单行距或热键标签与按钮之间的距离。

## 6. 四类布局

### A. 简单表单

常规、Everything、光标定位使用最大宽 640、左对齐的无外框设置组。普通行高 64；双行行高至少 72。标签到控件至少 24；控件统一右缘。下拉宽 192、高 32。开关轨道 40×20，命中区域 44×32。

双行主标签 14/20，辅助状态 12/18，间距 4；开关对齐整个文字组中心。此处采用视觉角色建议，不采用主标签单行对齐的候选方案。文字超过两行时按实际行高增长，不缩字体。

常规自启动文案准确写“登录 Windows 后自动启动 Simpilot”；语言辅助状态“立即保存”，不能暗示取消会恢复语言。低密度页不增添装饰内容。

Everything 两项是即时命令，使用“打开 Everything”“安装/修复服务...”的 32 高中性命令按钮，左对齐，行距 16。不用右向导航箭头泛指执行。沿用实际不可用状态和权限确认；没有结果信号时只能显示已发起，不能新增“服务正常”面板。

### B. 密集列表与编辑器

工具栏高 32；下面间距 12；表头高 32、表体行高 36、单元格左右内边距 12。表头 `navigation` 底，行白底；仅细横线，无全套竖向网格、斑马纹或行阴影。

长名称尾省略；长路径优先保留文件名、扩展名和末级目录，中间省略。完整原值在鼠标悬停及键盘聚焦时均可获取；不能改变保存的字符串。列表保持可见垂直滚动条空间，不用省略符代替滚动。

| 页面 | 固定列 | 弹性列与行为 |
| --- | --- | --- |
| 自定义热键 | 启用 64；热键 164；动作 112 | 目标占余宽；目标至少 248 |
| 键盘映射 | 启用 64；源按键 148；目标按键 148 | 用途和适用应用分配余宽 55:45，各至少 112 |
| 菜单图标 | 菜单 96；名称 176；图标来源 120 | 目标余宽，最小 240 |
| 程序选择 | 版本 112；修改时间 168 | 路径余宽，最小 360 |

宽度不足时保留列最小宽及水平滚动，不将最后一列推到不可访问区域。表头“适用应用”与底栏“应用”区分。无选择时编辑、删除和图标命令保持位置、禁用。列表空态在表头下 16、左内缩 12 放一条状态，不用插画或重复添加按钮。

图标列表的菜单归属显示统一为“主菜单 / 第二菜单”，与编辑器一致；菜单列宽仍为 96。此处只改归属标签，不改用户定义的菜单名称、内部编号或菜单浮层的自动入口名称。

空态选定文案：映射“暂无映射规则”；图标“暂无可设置图标的启动项”；菜单“主菜单暂无项目”或“第二菜单暂无项目”。有数据但无选中项才显示“未选择项目”。读取失败不是空列表。

快捷启动编辑器：主题控件仍归模块；主/第二菜单分段控件各 112×32。编辑区域左树默认 316、间隙 20、右侧余宽；左树最低 280、右侧最低 360。空间不足时左树取 280，右侧仍至少 360，正文水平滚动。树框 1 中性细线；右详情无外框、不加第二根竖分隔。树底四个结构图标按钮 32×32、间距 4；字段标签到输入 8、字段组间 16。删除靠近选中项标题，只用中性危险命令。

Windows 屏蔽页：每列内部为键名 64、间距 12、动作弹性、间距 12、开关 44；两列间距 32；行高 36。内容宽小于 704 时单列、保持按行字母序。去掉键名与动作之间重复长横线。开关列名“屏蔽”，开启代表屏蔽，不代表启用系统动作；Win+L 等平台限制不被样式改写。

### C. 模态对话框

边距 28；标题 24/32；标题后 24；分组标题 14/20；字段标签到控件 8；字段组间 16；控件高 32，录制高 36。表单可滚动，底部独立 72 高操作区。取消在左、保存或选择在右。

映射采用两等宽栏，间隔 24。每栏录制摘要弹性、间距 8、录制按钮最小宽 132。四个修饰键保留 2×2 选择网格、间隔 8；源保留主键与同时按下键，目标不添加不存在的 chord。下半部整行标签宽 88、间距 16、输入余宽；前台应用按钮最小宽 164，与输入间距 12。下半部与上半部分隔线上下各20；用途与适用应用行间12。精确匹配位于“适用应用”字段组下方，与输入起点对齐；单规则开关名“启用此规则”，不得与页面总开关混同。

自定义热键弹窗保留录制、组合键许可、动作、路径、参数、工作目录、权限、已运行行为、窗口状态全部功能。动作条件不适用时隐藏对应字段并重排，不留下空字段。紧凑动作表单内容宽 640；完整应用动作默认画布 968×694，对应客户区 968×664，使用上述共同控件与底栏，不强制缩到映射尺寸。字段文字换行时按实际行数每行增加 20，高度不足则仅表单正文滚动，底栏保持 72。

关于页默认画布 683×451，对应客户区 683×421，品牌/版本、产品信息、相关链接三个无框区域，区域间距 24。产品信息标签列 108，列间 12；正文 14/20，辅助信息 12/18。长文案每增加一行，正文区域增加 20；窗口超过工作区高度减 48 时限制外框高度并滚动正文。只有可执行链接使用蓝色，外部目标沿用真实行为。以上画布均包含第 2 节的模拟标题栏，原生外框由客户区计算。

### D. 弹出菜单

快捷启动主菜单、第二菜单和全部子菜单恢复 v1.0.0 比例：文本 15 DIP、正常字重；图标 24×24；左内边距 10；图标到文字间距 10，文字起点为 44。无图标项目保留相同槽位。普通项目右侧预留 16，子菜单项目预留 28，由 Windows 绘制箭头。

每级菜单独立按最长项目定宽，不设置默认宽或最小宽。项目测量宽度为 `min(实测文字宽 + 44 + 右侧预留, 360)`；系统非客户区另计。达到上限时名称尾省略，保留原始字符串与助记键，不改变启动目标。行高为 `max(34, 实测文字高 + 14)`；图标和文字垂直居中。分隔带高 9、线高 1，左右内缩 10。

浅色背景 `#FFFFFF`、文字 `#202124`、选中底 `#E7F1FA`、分隔线 `#E3E6EA`。深色分隔线 `#525252`，其余深色值沿用第 10 节。菜单边框、圆角、阴影、外围留白、子菜单位置及边缘翻转交由 Windows 管理，不强行模拟设计稿阴影或指定子菜单间隙。保留自动附加第二菜单入口、原分隔线、助记键和用户图标。

鼠标、键盘选择共享选中效果但焦点保持可辨。菜单穿越容错、悬停时序、左右键和 Esc 沿用原生机制，本规范不引入自制动画系统。这些交互尚未全部实测。

## 7. 全局热键专项

上区从正文左边缘起使用固定网格：

`标签132 + 间隔12 + 录制228 + 间隔8 + 清除32 + 间隔12 + 启用44`

总宽 468。上区不会随窗口横向拉伸。标签列右缘到录制框始终为 12，而不是按剩余宽度两端对齐；实际文字末端到录制框的距离随文案长度变化，不随窗口宽度变化。长中英文描述在 132 列内换行；不缩字体、不给单行额外宽度。

轻量列头高 20：左侧组名、热键、启用，分别对齐固定列。每条行高 56，录制框高 36居中。采用此密度，不采用早期审计提出的 48 候选值；保留五行自定义首屏是有意取舍。

录制值左对齐，右侧 16 图标表示录制；清除命中 32×32，与录制独立。清除名称为“清除[功能]快捷键”，不是删除功能。开关辅助名称包含功能名和启用动作。

自定义组与上区共用正文左缘，上区最后一条56行盒结束到工具栏为16；命令位于组工具栏右端；不是把下表各列强行对齐上方不同语义的列。窗口增高时只给自定义列表增加可见行。

## 8. 组件状态

| 状态 | 选定规则 |
| --- | --- |
| 正常 | 白表面、主文字、1 控件边界 |
| 悬停 | 中性 `hover`；主按钮 `accent.hover`；不移动、不改变大小 |
| 按下 | 中性 `pressed`；主按钮 `accent.pressed`；不缩放组件 |
| 选中 | `selection`，保留主文字与选择指示，不替代焦点 |
| 禁用 | `canvas` 表面、`text.disabled`、`line.subtle`；不响应；位置保留 |
| 焦点 | 2 `focus` 轮廓，距边 2；空间不足时内框；高对比度用系统焦点 |
| 错误 | `error` 边界、错误文字，可加局部 `error.surface`；不只染红 |
| 开关关 | 白轨道、1 控件边界，次文字色滑块在左 |
| 开关开 | accent 轨道，白滑块在右；滑块12，含1边界后的上下内边3；水平位置左3/右23 |
| 录制中 | 焦点轮廓、`selection` 底、明确录制状态，尺寸不变 |
| 危险命令 | 平时中性；悬停/焦点可用 error 文字；最终破坏性确认才用危险实心 |

不为操作新增不可实现的动画。允许开关 120 ms 位置过渡；系统减少动画时禁用；不作为交互流畅的验收证明。鼠标悬停不能抢键盘焦点。禁用和隐藏控件不进入正常 Tab 序列。

## 9. 保存与键盘语义

普通设置维持一个跨页草稿；切页不提交。应用成功留窗、清除脏状态；保存成功关闭；取消只放弃尚未应用的更改。无修改时应用禁用。

状态位选定：“有未应用的更改”“已应用”；错误使用真实原因，不显示成功。失败保留草稿、页和选择；确认草稿仍保留时，状态摘要为“未保存；更改仍保留”，下行显示真实原因。失败文字使用 `error`，左侧 16 错误图标、间距 8；仍遵守底栏两行上限及与按钮间隔 24 的约束。回滚失败须保留备份并报告，不能复用暗示完全恢复的摘要。语言即时保存只持久化语言项；Everything 命令不属于设置提交队列。

Tab 顺序：导航组 → 当前可见页内容 → 底栏；同区域按从上到下、从左到右。映射四槽按行进入。弹窗关闭回到触发入口。全局热键录制 Esc 取消录制，映射的裸 Esc 可录制，不能统一成关闭整个窗口。录制中按键不触发默认保存。

模态保存返回主设置草稿不等于全局已应用。跨模块热键冲突处理仍改双方草稿，取消不修改运行配置。设计稿未演示这些行为，不得据 PNG 宣称完成。

## 10. 主题与实现归属
