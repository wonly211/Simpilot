# v1.0.1 实现验证

日期：2026-09-27。此目录记录正式代码对统一视觉基线的实施，独立于上级目录的历史审计和离线提案。

## 实现范围

共享设施负责颜色、DIP 字体、按钮状态、列表表头、路径显示、原生图标命令、开关和滚动正文。模块继续拥有页面和功能配置，SettingsWindow 不新增模块分支。

设置默认客户区为 1028×684 DIP，最小客户区为 960×684 DIP（工作区不足时受屏幕约束）。功能热键使用固定 468 DIP 网格、12 DIP 标签间距、228 DIP 录制框、32 DIP 清除按钮和 44 DIP 开关命中区域。

映射和自定义热键弹窗保留全部字段，正文在空间不足时滚动，底部操作固定。快捷启动编辑器移除随高度缩放控件的逻辑；正文改用滚动区域。原生菜单仍由 Windows 管理定位、子菜单、边缘、外框及阴影，没有实现另一个菜单窗口系统。

## 验证边界

- 自动化测试中的 96/144/192 DPI 参数验证字体、列宽、控件几何和草稿行为，不等同于三种物理显示设置的截图。
- 原生预览使用本次 Release 静态库和真实页面代码；配置与列表内容均为临时模拟数据。它不注册全局热键，不安装服务，不运行菜单目标。
- 实际截图环境为 144 DPI。100%/200% 实际屏幕、系统高对比度、生产托盘宿主、真实键盘录制及 Everything 服务操作仍需单独人工验证。
- 系统文件选择器、系统提示和第三方窗口不重绘。定位效果的算法与绘制未在本版修改。
- 关于窗口允许因语言文字增长而高于默认提案客户区；工作区不足时滚动。
- 本目录截图必须标为原生实现，不使用上级 `proposals/` 图片充当产品验收。

## 本地验证

- MSVC x64 Release 构建成功；21 项 CTest 全部通过，包含配置回滚、模块边界、单钩子生命周期、捕获状态、设置草稿、菜单、关于及程序选择。
- 新增共享视觉测试：DIP 字体、正文与固定底栏、焦点滚入、Tab 顺序、精确尺寸下滚动条消失、长路径扩展名与 UTF-16 边界、语言切换后工具提示、无焦点时菜单分段选中态。
- 预览夹具 `--self-test` 通过。夹具使用真实实现，但系统执行与键盘录制被刻意隔离。
- 通过实际点击记录开关修改后的 `Unapplied changes`、应用后 `Applied` 及应用按钮恢复禁用；此处提交处理使用夹具模拟，不是系统持久化验收。真实配置提交和失败回滚由集成测试覆盖。
- 实拍发现并修复了长文件名丢失扩展名、双滚动条相互维持、reparent 后 Tab 顺序反转。代码复核另发现工具提示标识、分段选中态及路径首列图标绘制问题，均已修复。
