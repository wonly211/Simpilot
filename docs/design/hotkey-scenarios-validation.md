# v1.0.13 热键场景与名称验收

## 实现范围

自定义单键和组合键可按锁定键、后台运行程序或前台程序选择启动动作；前台和后台程序条件二选一，完整 EXE 路径匹配。可证明互斥的场景直接复用按键。重叠场景必须同时具有不同的显式优先级，数值较大的匹配场景胜出；编辑时确认保留两条规则。没有匹配时放行，低优先级默认动作由用户显式添加。

名称／备注可选，最多 128 个 UTF-16 单元，允许重复，不参与匹配。名称、条件、优先级随配置、全局备份和目录迁入保留。

## 本地验证

- Windows 11 x64 Release：完整 30 项 CTest，覆盖条件交集、优先级、按下释放、配置、三语界面参数、备份恢复、保存失败回滚及已有映射功能。
- 原 v1.0.12 配置读取器编译探针：格式 1 正常读取；格式 2 明确拒绝，不会忽略前台条件或优先级后执行。
- 产品钩子隔离探针：双后台场景、显式默认动作、前台切换、按住期间场景变化、进程退出重启和多次待执行动作分别保留进程实例。输入使用带重放标记的 F22/F23/F24，不等同于物理按键验收。
- 待执行进程判定采用固定容量 FIFO，过载拒绝新动作，不覆盖已有判断；动作消费后不可重用。发消息失败只撤回本次入队。
- 模块边界检查及 `git diff --check`。
- computer-use 检查实际简体中文编辑窗口：名称输入、上下滚动、前台／后台条件、完整优先级提示可见，优先级开关启用数字输入。取消退出隔离预览，未改动用户配置。
- 简体中文、繁体中文、英文分别覆盖 96／120／144／192 DPI 参数测试；不代表四种物理显示器实测。

本地日志保存在忽略的 `build/hotkey-scenarios-reviewed-{build,tests,native}.log`，旧读取器日志为 `build/hotkey-scenarios-old-reader.log`。

## 发布检查

正式发布必须使用该 PR 成功 CI 的 ZIP。CI 覆盖完整测试、各模块关闭、全部模块源码移除、安装清单、ZIP 白名单、文件版本和 SHA-256。合并提交与测试分支必须具有相同源码树。发布后重新下载正式附件，复核摘要和版本，并在独立 v1.0.12 目录覆盖升级，确认配置和缓存文件未改变。
