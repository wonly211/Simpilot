# 全局热键激活条件验收记录

检查日期：2026-10-11。开发基线为 v1.0.11，功能实现后按发布要求递增为 v1.0.12。中文、英文手册和 Wiki 源文档随代码更新。以下本地功能验收记录先于版本递增；正式制品与远端 CI 结果另见 v1.0.12 发布说明。

## 功能范围

- 自定义“启动程序／打开文件／打开文件夹”热键支持 Caps Lock、Num Lock、Scroll Lock 的不限制／开启／关闭条件，三项同时满足才触发。
- 程序运行条件最多保存 32 个 EXE 完整路径。规范化路径后忽略大小写，在当前登录会话中任意一个关联程序运行即满足；与锁定键要求同时生效。
- 进程监测仅在需要时启动，立即扫描后每 500 毫秒更新。键盘回调只读取快照并以零超时检查进程句柄；动作执行前再次检查。退出的旧实例不能因为进程重启而重新匹配旧快照。
- 锁定状态允许集合没有交集时可以复用组合键。不同程序列表不构成互斥证明；重叠条件沿用替换确认，显示双方条件。
- 首次按下固定触发或放行，重复按下不改选、不重触发。条件热键的 Win 拦截随本次按键生效，独立的手动屏蔽设置继续有效。
- 条件规则使用 `ConditionalGlobalHotKeyVersion=1` 的独立记录，无条件规则沿用旧记录，合并顺序通过 `Order` 保存。旧版本看不到条件规则，不会将其当成无条件执行。

## 自动化覆盖

| 范围 | 覆盖方式 |
| --- | --- |
| 锁定条件 | 27 种三态配置 × 8 种锁定状态；所有配置之间的交集；锁定键自身作为触发键；未知状态。 |
| 按键所有权 | 重复按下、按住时改变条件／修饰键、放行释放、注销后释放、录制／映射期间按下后结束捕获；组合条件必须同时满足。 |
| 冲突 | 互斥条件分别注册、移除条件引入冲突、不同关联程序仍视为可重叠、条件 Win 键不永久锁定屏蔽开关。 |
| 原生进程 | 测试创建的无窗口子进程、多实例、同名不同目录、退出、重启、快照过期／无效，以及监测服务启动和停止。仅清理测试创建的进程。 |
| 配置 | 新旧格式、顺序、中文路径、禁用规则、未知字段保留、缺失集合头／未知版本／非法枚举／非法路径／超限／格式损坏／重叠条件拒绝。 |
| 保存和备份 | 保存失败保留草稿并恢复运行状态；备份写出、读取、暂存、提交及再次启动；无效条件和内置热键冲突拒绝；不存在的程序保留并告警。 |
| 界面 | 三种语言 × 96／120／144／192 DPI 参数，检查三态选项、字体、列间隔、已有路径、空程序列表禁用保存及保存后条件一致。另在原生文件选择器中选择测试 EXE，验证添加成功及移除最后一项后禁止保存。 |

DPI 自动化通过窗口消息和布局参数测试，不等同于在四种实际显示比例或不同 DPI 显示器上移动窗口。

## Windows 11 隔离交互检查

使用 `simpilot_hotkey_activation_native_probe.exe`，它不读取或保存用户配置，不启动用户热键中的目标程序。通过窗口按钮发送带测试重放标记的按键，经过产品键盘钩子；这不是物理键盘输入验收。

- Num Lock 关闭／开启时，F24 分别计数到两个互斥动作，原始按下／释放均被消费。
- 关联子进程未运行时，F23 按下和释放均放行；启动无窗口子进程后触发动作；退出后恢复放行。
- F22 要求 Caps Lock 和 Scroll Lock 同时开启。均关闭或只开 Caps Lock 时放行，同时开启时触发。
- 退出探针后关闭测试子进程，恢复进入前的锁定键状态。
- 独立中文编辑窗口显示激活条件和滚动布局；三态下拉选项正确，启用空列表时禁止保存，取消程序限制后恢复保存，修改 Num Lock 条件可保存到预览结果。

用户原安装目录及其配置未更改。原生文件选择器已确认能打开和取消；桌面自动化未能完成输入路径的连续操作，因此不将它计为手动选择文件验收。

后续原生集成测试通过直接操作测试进程自己的文件选择器，完成了 EXE 选择、添加和移除检查。Windows 11 的文件名框位于嵌套控件中，测试改为定位该控件，未再依赖不起作用的旧式顶层对话框消息。

## 回归中修正的问题

既有快捷菜单编辑器通过人工发送 `WM_DPICHANGED` 通知自身更新 DPI。模块裁剪回归时发现部分此类消息没有到达窗口，导致仍以 96 DPI 布局。`set_dpi` 现在直接更新字体、分栏和布局，实际系统 DPI 消息也复用该入口。原滚动测试连续三次通过，未删除或放宽原断言。

另外补充了录制／映射按住期间不能转为条件热键的状态保护、恢复时同步错过的释放状态、打开进程句柄后再核实所属会话、缩放后程序路径列表的水平范围刷新，以及非法路径检查。条件 Win／Alt 组合键的菜单取消使用既有 Win 屏蔽流程所用的未分配键，覆盖 Win＋非字母键；普通条件热键不再额外发送 Ctrl+Break。

## 未实测环境与边界

- Windows 10 桌面；真实混合 DPI 显示器；系统高对比度模式。
- 真正的休眠恢复、锁屏／安全桌面切换及条件 Win 组合键的物理输入。
- 受保护进程权限失败以无法查询／无效快照的关闭行为检查覆盖，未建立另一登录会话或修改系统进程权限。
- 不将模型测试、参数化窗口测试或带重放标记的输入描述为上述物理环境测试。
