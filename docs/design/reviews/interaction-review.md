### 分类与优先级

- **可观察问题**：图片直接呈现的布局、文案或状态表达缺口；不外推其运行行为。
- **推断**：可能的理解或操作风险，必须补交互证据验证；不写成已经发生的故障。
- **P1**：优先解决，影响状态理解、操作对象或首次建立内容。
- **P2**：随后解决，影响扫描效率、关联、可发现性或一致性。
- **P3**：精修项，不应压过语义和可用性。首批无足够证据提出 P0 阻断问题。

## 2. 总体判断

保留现有骨架：固定左导航、明确页标题、浅色工作区、固定提交栏。蓝色主要用于选中项、开启态和“保存”，品牌红色局限于标识，方向已经接近克制的原生工具。不要换成营销式大标题、装饰卡片、渐变背景或满页图标。

主要不足不是“空白太多”，而是空白区域没有交代内容状态、关联操作距离过远，以及部分符号未表达动作对象。低密度页面可以留白；应缩短设置项内部的关联距离，而不是用说明和装饰填满窗口。

## 4. 统一交互规则

以下为后续设计及验收约束，不是本轮已验证的行为。

### 4.1 操作层级与保存语义

| 层级 | 规则 |
| --- | --- |
| 窗口提交 | “保存”为唯一填充主按钮，应用全部待提交更改，成功后关闭；“应用”为次按钮，成功后保持窗口；“取消”放弃尚未应用的更改并关闭。已应用内容不随取消撤销。保留现有离开确认语义。 |
| 页面创建 | 添加、添加分类、添加启动项、添加分隔线保持局部次级命令，不与“保存”争夺主色。按既有能力提供，不增加批量、搜索、导入或向导。 |
| 选择相关 | 编辑、删除、图标操作、结构操作依附当前选择；不可用时保留位置并明确上下文，不制造布局跳动。删除用既有保护边界，不凭空增加撤销系统或一律新增确认弹窗。 |
| 行内工具 | 清除、录制、上移/下移等采用一致的原生工具图标与焦点反馈。含义不够自明的动作保留文字，尤其层级调整和安装/修复。 |
| 即时例外 | 语言按既有语义即时保存。Everything 两项为独立命令，不进入设置提交队列；系统确认及结果必须与窗口保存区分。菜单主题仍是菜单主题，不扩展成全 App 主题功能。 |

补充边界：

- 改动开关或列表中的草稿值，不应仅因显示为开启就声称运行时已经生效。
- 无待提交更改时“应用”不可用；“保存”不要因其颜色醒目就被认定为错误，也不要擅自改成自动保存或无修改时完全无法关闭。
- 页面切换保持同一设置会话的未提交更改，不引入每页独立保存语义。
- 保存失败不能关闭窗口或显示成功，应保留可修正的数据和相关上下文。
- 模态内部的确认与设置窗口最终提交要分层表达；具体按钮及反馈待模态截图后核验。

### 4.2 Tab、焦点与键盘

| 范围 | 统一规则与后续验证点 |
| --- | --- |
| 整体次序 | 页面导航进入当前页可见控件，再进入底部提交栏；同一平面按视觉阅读顺序。Shift+Tab 可逆，禁用及隐藏控件不进入正常 Tab 序列。不要重新发明与原生控件冲突的快捷键。 |
| 左侧导航 | 作为一个导航组进入，方向键定位页面；选中页与当前键盘焦点独立表达。键盘切页后焦点保持可预期，下一次 Tab 进入新页，不跳到保存或旧页隐藏控件。 |
| 局部 Tab | N08 主菜单/第二菜单按一个 Tab 组处理，左右键切换；切换不隐式提交。当前面板拥有后续焦点顺序，保留其已有选择和编辑语义。 |
| 开关及按钮 | 空格操作已聚焦开关；常规按钮沿用原生键盘激活。每个开关的辅助名称包含对象与动作，N05 必须包含“屏蔽”。不只依赖蓝/灰区分状态。 |
| 列表与树 | 集合整体进入后以方向键浏览；行内已有可编辑能力必须有键盘可达路径。空列表能被识别为空但不吞掉焦点；删除后移至相邻项，无项时移至已有添加入口。具体实现待实测，不能假定现有 UI 自动满足。 |
| 对话框 | 打开时进入首个相关字段，关闭回到触发入口；校验失败指向实际错误，不夺走无关输入。模态截图未提供，本轮未验证。 |
| 录制例外 | 不能把 Esc 一律解释成取消整个窗口。手册区分全局热键录制的 Esc 取消与键盘映射的裸 Esc 可录制；新视觉不能抹掉该差异。录制时也不能让组合键误触发默认“保存”。 |
| 焦点外观 | 沿用系统可见焦点或等价清晰描边，选中底色不能替代焦点。焦点不被底栏或滚动边界裁切；高对比度与缩放需后续实际验证。 |

### 4.3 图标语义

- 同一动作使用同一图形：加号为添加，铅笔为编辑，垃圾桶为删除，`×` 为清除当前字段或关闭对应容器，必须由位置与名称消除歧义。
- 导航箭头只表示前往/展开，不能同时泛指安装、修复、启动。N03 优先使用明确命令按钮。
- 上下箭头表示排序移动；改变树层级使用缩进语义图标。维持当前产品动作，不借图标改写升级/降级规则。
- 图标按钮具备独立、稳定的命中区域；图形小不等于命中区域小。精确尺寸在原生 DPI 下确认，不按 JPEG 像素生搬。
- hover 与 keyboard focus 都能获得准确名称；无障碍名称应能独立表达动作和对象。提示不能成为当前错误、禁用原因或空状态的唯一载体。
- 保留已有品牌图标，不给每行设置额外添加装饰图标，也不为视觉统一改造用户自定义菜单图标。

### 4.4 空列表与无选择

| 状态 | 表达及动作 |
| --- | --- |
| N06 真空列表 | “暂无映射规则”；保留表头和现有添加入口，总开关状态不变；编辑/删除不可用。 |
| N07 无可配置项 | “暂无可设置图标的启动项”；不暗示所有类型都支持手动图标，不新增本页创建功能。 |
| N08 当前菜单为空 | 用实际当前菜单名表达“主菜单暂无项目”或“第二菜单暂无项目”；现有添加工具仍可发现，编辑区不再要求选择不存在的项目。 |
| 有数据但无选择 | 数据仍可见，详情区表达“未选择项目”，依赖选择的命令不可用。不要误显示“暂无项目”。 |
| 数据读取失败 | 仅在真实错误已知时显示失败原因及已有恢复途径；不能以空列表掩盖失败，不能为完整状态矩阵虚构重试按钮。 |

空态是数据状态，不是新手教程或装饰插画。使用一条低强调状态文本即可，不增大容器、不添加重复主按钮、不把表格嵌入多层卡片。

### 4.5 状态反馈

| 时点 | 统一表达 |
| --- | --- |
| 未修改 | 提交栏保持稳定，“应用”不可用，不显示虚假的未保存警告。 |
| 待应用 | 在固定状态位表达“有未应用的更改”，保持已编辑值；不要为每个开关都制造通知。 |
| 应用成功 | 保持窗口和选择，状态位表达“已应用”，脏状态清除；不得只靠按钮变灰传达成功。 |
| 保存成功 | 沿用成功后关闭，不强行为已关闭窗口设计持久成功条。 |
| 校验失败 | 使用真实错误内容，保留上下文，定位对应页/项/字段；错误文字不能仅由红色表达。 |
| 写入或执行失败 | 区分“设置未保存”和“外部命令未完成”；只反馈已知结果，不保证尚未观测的运行效果。 |
| 语言即时保存 | 与全局待应用状态区分；取消其余草稿不声称恢复语言。 |
| 外部命令 | 发起、系统权限取消、失败、成功分别对应真实可获取结果。没有服务结果证据时不能显示“服务正常”。 |

当前源码中可读到待修改、已应用及失败状态的处理，这只说明代码存在相关路径，不证明这些截图展示过相应反馈，也不证明运行时表现正确。后续应核验可见性、持续时间及焦点关系，而不是重复新增另一套状态机制。

### 4.6 视觉约束

- 浅色工作底、轻微区分的侧栏、白色数据面和克制的分隔线即可；保留红色品牌与蓝色交互强调，避免整页蓝染。
- 统一页标题、组标题、正文、次要状态四级层次。空态和无选择提示不能大于真实编辑标题。
- 不将低密度页面强行填满；简单设置收束行宽，数据页优先保证列宽、树和编辑区域的有效空间。
- 按钮、Tab、图标命中区采用稳定尺寸；不同文字长度不能使整排控件跳动。中文、英文与缩放下靠换行和布局伸缩处理，不靠缩小到难读。
- 禁用态要与正常态可辨，同时保留名称辨认；不将当前截图中的浅灰文字直接判为对比度不合格，需原生渲染测量。
- 优先系统原生控件和现有图标体系，小圆角、少阴影，不做卡片套卡片或装饰性容器。

### 7.4 统一规则补充

- **长文本**：名称、用途、路径分别处理，不使用一种尾部省略策略覆盖全部列。路径保留末端目标、名称保留辨识主体、用途保留摘要；所有显示省略都不得修改底层值。静态证据只确认发生了省略，不证明完整值无法取回。
- **列表密度**：优先调整组间留白及弹性列宽，不缩小字体来填满页面。底部露出部分下一行可作为滚动线索，不能仅凭半行就登记为裁切故障；只有滚动后仍无法完整阅读才形成行为问题。
- **作用范围**：页面总开关、单条规则启用、适用应用、录制范围和提交范围必须分别命名；不能让相同“启用”或“保存”隐含不同对象而毫无上下文。
- **模态提交**：保留原有“保存 / 取消”语义及原生默认按钮表达，不为复制主窗口按钮位置而机械调换模态顺序。整个对话框只设置一个清晰确认动作；禁用态、默认按钮态、键盘焦点态必须可区分，不能只按某一张图的蓝色描边判定。
- **表单焦点**：N18 按录制区域、执行操作、对应字段、运行选项、提交区组织；N21 先完整源组，再完整目标组，再用途/适用应用/规则状态，最后提交区。每组按视觉顺序，浏览与录制命令紧跟其字段。此为验收目标，不是已测 Tab 顺序。
- **状态反馈**：单项保存返回后，若产生草稿变化，应由现有窗口待应用机制反馈；不能弹出“已生效”掩盖尚待应用的事实。N18 空输入时没有错误提示并不自动构成缺陷，也不建议在用户尚未输入时满屏报错。
- **视觉克制**：保留 N21 清楚的源/目标双栏和 N18 的功能分组，以间距、对齐和简短字段名改善密度；不引入新向导、装饰卡片、录制动画或测试按钮。
