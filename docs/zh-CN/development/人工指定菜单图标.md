# 人工指定菜单图标

适用版本：Simpilot 0.18.0 及后续版本。

## 功能范围

“设置 > 菜单图标”页面允许用户替换主菜单或第二菜单中可用本地程序和文件的自动图标。此功能只负责为单个启动操作指定图标，不是完整图标管理器：不提供图标包、在线图标源、网址图标、PNG/SVG 转换、批量操作或分类图标。

## 选择图标

- 选择一个菜单启动项，然后点击“选择图标...”。
- Windows 图标选择器支持 ICO 文件，也可浏览 EXE 和 DLL 文件。
- EXE 或 DLL 包含多个图标时，选择器会显示可用图标并保存所选索引。
- 所选图标会转换为带透明背景的 128×128 ICO 文件。转换完成后，快捷启动菜单不再依赖原图标源文件。

## 存储与项目身份

自动图标和人工图标统一存放在 `Cache\RunIcon`：

```text
Cache/
  RunIcon/
    <target-hash>.ico
    <target-hash>.custom.ico
```

图标按完整启动操作区分，包括启动项类型、程序或文件路径、命令行参数和管理员运行状态。因此，不同 Chrome 配置、Chrome 应用 ID 或 `explorer.exe shell:::{GUID}` 命令即使使用同一个 EXE，也可以分别指定图标。只有启动操作完全相同时，主菜单和第二菜单中的项目才会共用图标。

人工图标优先于自动缓存图标。“恢复自动图标”只删除对应的 `.custom.ico`；下次显示菜单时会重新使用自动图标。

删除整个 `Cache\RunIcon` 会同时清除自动图标缓存和所有人工图标，但不会修改 `Simpilot.ini`、`Simpilot2.ini` 或其他设置。

## 生效方式

选择或恢复图标后，Simpilot 会立即写入缓存并清除当前菜单的内存图标缓存。下次打开快捷启动菜单时即可看到更新，无需重启 Simpilot。

图标操作直接修改缓存文件，因此不受设置窗口“保存”和“取消”按钮控制。
