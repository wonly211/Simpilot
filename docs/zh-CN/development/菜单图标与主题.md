# 菜单图标与主题设计

适用版本：Simpilot 0.18.0 及后续版本

## 1. 功能范围

0.7.0 为原生 Win32 弹出菜单增加自动图标和独立主题设置，不引入 WinUI 3，也不改变 `Simpilot.ini` 与 `Simpilot2.ini` 的菜单语法。

- 应用条目：从菜单解析后的实际可执行文件提取图标；
- 网址条目：使用 Windows 的 Internet 快捷方式图标；
- 分类和第二菜单：使用 Windows 文件夹图标；
- 分隔线：使用与弹出菜单主题匹配的自绘线条，不添加图标。

图标只用于快捷启动菜单。托盘右键菜单继续使用简洁的系统命令样式。

## 2. 图标来源与缓存

菜单完成变量展开、相对路径解析、PATH 查找和 Everything 定位后，图标模块读取条目的最终目标。0.7.1 通过 `SHGetFileInfoW` 确定系统图标索引，并从 Windows `SHIL_JUMBO` 高分辨率系统图像列表提取图标；网址和分类通过 `SHGFI_USEFILEATTRIBUTES` 获取对应的 Windows Shell 类型图标。若应用没有足够大的原生图标、系统返回小图标居中的占位结果，则改用可缩放的 `SHIL_EXTRALARGE` 图标生成完整的 128×128 缓存。高分辨率接口不可用时退化为普通系统大图标，不影响菜单使用。

图标缓存统一位于程序目录下：

```text
Cache/
  RunIcon/
    <目标哈希>.ico
```

Simpilot 以规范化目标路径生成稳定的缓存文件名。首次提取后保存为带透明通道的 128×128 `.ico` 文件，后续启动优先从磁盘缓存加载；运行期间再使用一层内存缓存，避免同一目标重复读取。主菜单和第二菜单共享缓存。源程序或快捷方式的修改时间晚于缓存时会重新提取并覆盖对应文件。

`Cache/RunIcon/` 只存放自动图标缓存和人工图标文件，不写入 `Config` 或 `Log`。人工图标在“设置 → 菜单图标”页管理；快捷启动菜单编辑器不提供图标修改入口。

图标提取失败不会隐藏菜单项，也不会影响命令执行；该项会退化为无图标的原生菜单文本。

## 3. 主题设置

常规设置页提供“弹出菜单主题”：

- 跟随 Windows：每次打开菜单时采用当前 Windows 应用主题；
- 浅色：强制 Simpilot 弹出菜单使用浅色；
- 深色：强制 Simpilot 弹出菜单使用深色。

设置保存在 `Config\Setting.ini`：

```ini
[General]
MenuTheme=0
```

`0` 表示跟随 Windows，`1` 表示浅色，`2` 表示深色。保存设置后无需重启 Simpilot；下一次打开快捷启动菜单或托盘右键菜单时生效。

主题控制通过 Windows 10 1903 及更高版本的 `uxtheme.dll` 菜单模式入口实现。调用前会检查 Windows 构建版本和入口是否存在；不支持时保持 Windows 默认菜单外观，不影响 Simpilot 启动、菜单显示或命令执行。

## 4. 生命周期与边界

- 菜单仍由 `CreatePopupMenu` 和 `TrackPopupMenu` 创建和管理；
- 快捷启动条目使用 `MFT_OWNERDRAW` 轻量自绘，直接通过 `DrawIconEx` 绘制透明 `HICON`，避免位图透明通道被绘制成黑色；
- 基准尺寸为 24px 图标、15px Segoe UI 文字和至少 34px 菜单项高度，并按 DPI 等比例放大；
- 子菜单箭头只由 Windows 绘制一次；自绘层仅预留箭头空间，避免系统箭头与自定义箭头重叠；
- 快捷启动菜单的分割线同样使用自绘，在浅色、深色和高对比度模式下分别采用匹配的背景与线条颜色；
- Windows 继续负责菜单弹出、键盘导航、子菜单状态、箭头、阴影和窗口生命周期；
- 主题只影响 Simpilot 弹出菜单，不修改注册表中的 Windows 主题设置；
- 高对比度等系统无障碍模式的最终呈现由 Windows 主题引擎决定。

## 5. 菜单与设置窗口协调

`TrackPopupMenu` 在菜单打开期间运行嵌套消息循环。如果此时由全局热键直接进入设置窗口的模态消息循环，会同时保留启动菜单和设置窗口，造成输入焦点互相等待。

0.7.0 在收到设置请求时先记录待处理状态并调用 `EndMenu()`。待 `TrackPopupMenu` 返回、菜单句柄销毁且自绘资源释放后，再向主消息窗口投递打开设置的消息。设置窗口因此始终在启动菜单完全关闭后创建，不再需要用户按 `Esc` 手动解除嵌套状态。

## 6. 快捷启动菜单定位

0.7.1 以鼠标指针为快捷启动根菜单的锚点，并根据指针所在显示器的工作区选择展开方向：右下空间充足时绑定菜单左上角；下方不足时绑定左下角；右方不足时绑定右上角；两侧均不足时绑定右下角。工作区计算会避开任务栏，并支持多显示器。各级子菜单继续由 Windows 自动选择展开方向，托盘右键管理菜单保持原有定位方式。
