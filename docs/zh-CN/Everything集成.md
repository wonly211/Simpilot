# Everything 集成

简驭使用同目录 `Everything/Everything64.dll` 通过 Everything IPC 查询默认实例的索引数据库；文件搜索并不依赖特定 `Everything.exe` 路径。

启动时，简驭会先尝试连接已经运行的默认 Everything 实例。连接成功时直接复用其数据库；未找到可用实例时，会尝试启动随包 `Everything/Everything.exe`。Everything 不可用时，快捷启动菜单和大多数全局热键仍可正常工作，只是以下能力会受影响：

- 打开 Everything 搜索窗口；
- 解析只填写了程序文件名、未填写完整路径的启动项；
- 为同名可执行文件提供候选路径选择。

当同名程序有多个候选项时，简驭按文件版本号、修改时间、完整路径的顺序排序，并显示图标、路径、版本和修改时间供用户确认。

Everything 服务的安装或修复可从托盘右键菜单的“维护”中执行，需要 Windows 管理员授权。服务不是简驭启动的前提。

Everything 使用命名实例而非默认实例时，简驭可能无法连接它，随后会尝试启动随包的默认实例。
