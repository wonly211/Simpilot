# 简驭 | Simpilot 设置界面设计规范

适用版本：0.18.0 及后续版本。

## 1. 命名

所有用户可见的产品标题统一使用“简驭 | Simpilot”。可执行文件、配置文件、日志文件、窗口类名和注册表键继续使用稳定的 `Simpilot` 技术名称。

设置窗口采用左侧导航，页面顺序固定为“常规”“快捷启动菜单”“菜单图标”“全局热键”“Windows 快捷键屏蔽”。“主菜单 / 第二菜单”只作为快捷启动菜单页内的二段切换，不再使用独立窗口或嵌套页签。

## 2. 视觉层级

- 普通文字、标签、按钮、输入框和列表：13；
- 分区标题：16 Semibold；
- 页面标题：20 Semibold；
- 窗口边距：24；
- 输入框高度：34；
- 按钮高度：36；
- 同组控件间距：8～12。

设置相关窗口使用独立的浅色中性界面，不继承快捷启动菜单的深色主题。页面背景为 `#F5F6F7`，左侧导航为 `#EFF1F3`，输入框和列表为白色，正文为 `#202124`，说明文字为 `#5F6368`，选中态使用 `#E5F0FA`，强调色为 `#0067C0`。Windows 高对比度模式下使用系统颜色。

所有静态文字和开关使用透明背景，不允许出现逐段的灰色色块。列表不显示网格线，保留表头、整行选择、双缓冲和文本提示。

## 3. 热键录制

内置热键和自定义热键统一使用原生录制按钮。未设置时显示“录制热键”，已有按键时显示“按键 · 重新录制”，录制期间显示“正在录制…（Esc 取消）”。只有点击按钮或使用键盘激活按钮后才进入录制，`Tab` 聚焦不会自动开始。`Esc` 取消本次录制并保留原值；`Backspace` 是普通可录制按键，不承担清除功能，移除按键只使用相邻的“清除”按钮。

## 4. 滑动开关

内置热键、自定义热键列表和 Windows 快捷键屏蔽统一使用同一套滑动开关视觉。独立开关保留原生 `BUTTON / BS_AUTOCHECKBOX` 的点击、空格键、焦点和辅助功能语义，只对子类化后的绘制进行替换；列表继续使用原生状态图像和复选状态，只把状态图像绘制为滑动开关。

96 DPI 下轨道为 `40×20`，滑块为 `16×16`，最小点击区域为 `44×32`。开启轨道使用 `#0067C0`，关闭状态使用 `#767676` 边框；滑块左右位置必须明确表达状态，不能只依赖颜色。被全局热键联动的 Windows 快捷键显示为开启且锁定，并附带“由全局热键启用”的文字。高对比度模式回退为系统复选框外观；DPI 或系统主题变化时重新生成列表状态图像。

## 5. 主题边界

`MenuTheme` 只控制快捷启动菜单和托盘右键菜单。显示设置窗口、菜单编辑器和相关模态窗口时使用设置界面的独立浅色样式；弹出菜单关闭后立即恢复浅色应用模式，避免菜单主题污染设置控件。
