# 简驭 | Simpilot 用户手册

适用版本：0.16.0

简驭 | Simpilot 是一款常驻 Windows 托盘的快捷启动器和全局热键管理器。它可以把常用应用、文件夹、文件和网址整理成分层菜单，也可以通过全局热键直接打开指定目标，并在程序运行期间屏蔽选定的 Windows 快捷键。

## 1. 安装与首次启动

### 1.1 系统要求

- Windows 10 或 Windows 11
- x64 处理器与操作系统
- 一个当前用户可以正常写入的程序目录

### 1.2 安装

简驭采用便携方式发布，不需要安装程序。

1. 从 [GitHub Releases](https://github.com/wonly211/Simpilot/releases/latest) 下载 `Simpilot-0.16.0-win-x64.zip`。
2. 将压缩包完整解压到一个固定目录。
3. 确保 `Simpilot.exe`、`Everything` 和 `Languages` 目录保持在原有相对位置。
4. 双击 `Simpilot.exe`。

建议选择当前账户可以正常写入的目录。简驭会在程序目录中创建配置、缓存和日志；不要只在压缩包预览窗口中运行，也不要仅复制 `Simpilot.exe`。

发布目录的主要内容如下：

```text
Simpilot.exe
Everything/
  Everything.exe
  Everything64.dll
  Everything.lng
  Everything.ini
Languages/
  en-US.json
  zh-CN.json
  zh-TW.json
```

发布页同时提供 `.sha256` 校验文件。如需核对下载内容，可在 PowerShell 中运行：

```powershell
Get-FileHash .\Simpilot-0.16.0-win-x64.zip -Algorithm SHA256
```

将结果与 `.sha256` 文件中的值比较。当前发布包尚未进行数字签名；若 Windows SmartScreen 首次运行时提示未知发布者，请先确认文件来自本仓库的正式 Release，并完成校验后再决定是否运行。

### 1.3 首次启动会发生什么

首次启动后，简驭不会显示普通主窗口，而是在 Windows 通知区域显示托盘图标。若任务栏没有直接显示该图标，请在通知区域的隐藏图标中查找。

程序会自动创建 `Config/Simpilot.ini`，其中包含记事本、计算器和 OpenAI 等示例启动项。默认界面语言为简体中文，默认快捷启动菜单热键为反引号键（通常位于 `Esc` 下方、数字 `1` 左侧）。

简驭还会检查 Everything 的默认实例和数据库。已有可用 Everything 时优先复用；没有可用数据库时，会尝试启动发布包中 `Everything/Everything.exe`。Everything 不可用不会阻止简驭启动，但可能影响无完整路径程序的查找和 Everything 搜索功能。

## 2. 托盘图标与菜单

### 2.1 左键：快捷启动菜单

左键单击简驭托盘图标，只会显示快捷启动菜单。选择启动项即可打开对应的应用、文件夹、文件或网址；带有右箭头的分类可以继续展开。

菜单以鼠标位置为锚点，并根据当前显示器的可用空间自动选择向右、向左、向上或向下展开。菜单图标和文字会随显示器缩放比例调整。

### 2.2 右键：管理菜单

右键单击托盘图标，只会显示设置和维护相关项目：

- **设置...**：打开完整设置窗口。
- **语言**：在简体中文、繁體中文和 English 之间切换。
- **维护 > 刷新菜单**：立即重新读取主菜单和第二菜单配置。
- **维护 > 打开 Everything**：打开或恢复 Everything 搜索窗口。
- **维护 > 安装/修复 Everything 服务...**：请求管理员授权，并使用随包 Everything 修复默认服务。
- **关于 简驭 | Simpilot**：查看当前版本。
- **退出**：退出简驭并解除其运行期间注册的热键和快捷键屏蔽。

`Simpilot.ini` 和 `Simpilot2.ini` 发生变化时通常会自动刷新，因此“刷新菜单”主要用于手动重试或确认刚才的修改。

Windows 资源管理器重启后，简驭会自动重新注册托盘图标，无需退出并重开程序。

## 3. 设置窗口

设置窗口左侧包含五个页面：

1. 常规
2. 快捷启动菜单
3. 菜单图标
4. 全局热键
5. Windows 快捷键屏蔽

窗口底部按钮的含义：

- **保存**：应用全部更改并关闭设置窗口。
- **应用**：应用全部更改，但保持设置窗口打开。
- **取消**：放弃尚未应用的设置并关闭窗口。

语言切换会立即保存并刷新界面，不受“保存”或“取消”影响。其他设置通常需要点击“应用”或“保存”后生效。

> 设置窗口打开期间，最后一次已应用的内置热键和自定义热键继续生效。只有点击“录制热键”并实际录制按键时，键盘事件才会临时交给录制功能；录制结束或取消后立即恢复。

## 4. 常规设置

### 4.1 登录 Windows 后自动启动

打开“登录 Windows 后自动启动简驭 | Simpilot”，再点击“应用”或“保存”。此设置只对当前 Windows 用户生效，不需要管理员权限。

移动整个 Simpilot 目录后，请重新打开设置并应用一次开机启动选项，使启动位置同步为新路径。

### 4.2 显示语言

简驭内建三种界面语言：

- 简体中文
- 繁體中文
- English

选择后立即切换，无需重启简驭或 Windows 资源管理器。当前设置页面、尚未应用的其他设置和列表选择会保留。用户自己填写的菜单名称、分类名称和目标路径不会被翻译。

语言选择保存在 `Config/language.txt`。如果当前语言资源缺少某段文字，简驭会使用英文文本；资源仍缺失时会显示 `[missing translation]`，而不是显示空白按钮。

### 4.3 快捷启动菜单主题

- **跟随 Windows**：菜单打开时采用当前 Windows 应用主题。
- **浅色**：始终使用浅色弹出菜单。
- **深色**：始终使用深色弹出菜单。

主题只影响简驭的快捷启动菜单和托盘右键菜单，不修改 Windows 系统主题。点击“应用”或“保存”后，下次打开菜单时生效。

## 5. 编辑快捷启动菜单

打开“设置 > 快捷启动菜单”。该页面同时管理主菜单和可选的第二菜单。

### 5.1 主菜单与第二菜单

- **主菜单**读取 `Config/Simpilot.ini`，可通过托盘左键或“快捷启动菜单”内置热键打开。
- **第二菜单**读取 `Config/Simpilot2.ini`，可为它单独录制热键；触发后会直接显示第二菜单。

第二菜单不是必需的。添加内容并保存后，简驭会按需创建 `Simpilot2.ini`。

### 5.2 添加内容

左侧目录树上方提供三种操作：

- **添加分类**：创建可以继续包含其他项目的分类。
- **添加启动项**：创建应用、文件夹、文件或网址入口。
- **添加分隔线**：在同级项目之间增加视觉分隔。

新增项目会出现在当前所选位置附近。选中左侧项目后，可直接在右侧编辑内容。

### 5.3 编辑启动项

启动项支持以下操作类型：

- **打开应用**：打开程序，可填写命令行参数并选择“以管理员身份运行”。
- **打开文件夹**：使用文件资源管理器打开目标目录。
- **打开文件**：使用 Windows 默认关联程序打开目标文件。
- **打开网址**：使用默认浏览器打开以 `http://` 或 `https://` 开头的网址。

“浏览...”可以选择本地目标。路径中包含空格时，编辑器会在保存时自动处理引号。

如果“打开应用”只填写了程序名，例如 `tool.exe`，右侧会显示“当前解析路径”。该路径来自 Windows 系统目录、`PATH` 或已确认的 Everything 选择。对于 Everything 定位的项目，可以点击“重新选择...”再次读取候选并纠正之前的选择；无需删除缓存文件或等待原目标失效。

### 5.4 分类、顺序和层级

选择左侧项目后，可使用目录树下方的按钮调整结构：

- **上移 / 下移**：改变同级项目顺序。
- **升级 / 降级**：调整项目所在层级。
- **删除**：删除选中项目；删除非空分类前会再次确认。

左右区域之间的分隔条可以拖动，用于调整目录树和编辑区域的宽度。

### 5.5 菜单快捷键

分类和启动项都可以填写一个“菜单快捷键”。保存后，简驭会在左侧树中以 `[A]` 形式显示该字符，并自动生成菜单所需的访问键标记。用户不需要在名称中手动输入 `(&A)`。

快捷启动菜单打开时，按下对应字符可以选择分类或执行启动项。同一分类下使用了重复字符时，左侧树会高亮提示；不同层级之间可以重复。

菜单快捷键只在菜单已经打开时使用，它与随时可触发的全局热键不是同一种功能。

### 5.6 保存和外部修改

点击设置窗口的“应用”或“保存”后，编辑器会校验并写入两份菜单配置。无效名称、空目标或格式不正确的网址会阻止保存，并将对应项目选中供修改。

如果编辑期间配置文件被其他程序修改，保存前会询问是否覆盖外部更改。选择不覆盖即可保留外部版本。

简驭会实时监听菜单配置。直接使用文本编辑器修改并保存 UTF-8 文件后，快捷启动菜单也会自动刷新；读取失败时会继续使用上一份有效菜单。

## 6. 全局热键

打开“设置 > 全局热键”。全局热键在简驭运行且设置窗口已关闭时可用。

### 6.1 录制、清除和启用

录制方法：

1. 点击“录制热键”或已有热键的“重新录制”按钮。
2. 按下需要使用的单键或组合键。
3. 录制完成后，按“应用”或“保存”。

录制期间，按键用于简驭记录，不会继续执行对应的普通应用或 Windows 快捷操作。按 `Esc` 会取消本次录制并保留原值。

“清除”会移除当前热键并关闭该项。关闭右侧开关只会暂停热键，不会删除已录制的组合。`Backspace` 是普通可录制按键，不用于清除。

### 6.2 内置热键

简驭提供四项不可删除的功能热键：

| 功能 | 初始热键 | 初始状态 |
|---|---|---|
| 快捷启动菜单 | 反引号键 | 启用 |
| 第二菜单 | 未设置 | 关闭 |
| 设置窗口 | 未设置 | 关闭 |
| Everything 搜索 | `Win+S` | 关闭 |

“Everything 搜索”不依赖用户填写的程序路径，而是直接调用简驭的 Everything 管理功能。

### 6.3 添加自定义全局热键

点击“添加”，然后完成以下设置：

1. 录制按键或组合键。
2. 选择“打开应用”“打开文件夹”或“打开文件”。
3. 选择存在的目标。
4. 若为应用，可继续设置参数、启动目录、运行权限、程序已运行时的处理方式和启动后窗口状态。
5. 保存新热键，再点击设置窗口的“应用”或“保存”。

应用动作的“程序已运行时”选项：

- **显示窗口**：优先恢复并显示已有窗口；若已有进程没有可用窗口，则再次调用该程序，让程序自身处理恢复或单实例逻辑。
- **启动新实例**：始终再次启动程序。
- **不执行操作**：检测到同一路径的程序已经运行时，不执行任何操作。

“打开文件夹”和“打开文件”由 Windows 直接处理，不使用应用参数、管理员身份、重复启动策略或窗口状态。

自定义热键列表中的开关可以单独暂停某项。选中项目后可编辑或删除。

### 6.4 热键冲突

保存热键时，简驭会检查：

- 是否与内置热键重复；
- 是否与其他自定义热键重复；
- 是否已被 Windows 或其他程序注册。

发生冲突时，简驭会说明将要替换或尝试覆盖的内容，并等待确认。请只覆盖自己明确了解的组合。

精确的 `Win+A` 到 `Win+Z` 会与“Windows 快捷键屏蔽”联动。`Win+L` 是 Windows 安全锁定快捷键，不能设置为简驭全局热键。`Ctrl+Alt+Del` 等 Windows 安全组合也无法由普通桌面应用覆盖。

## 7. Windows 快捷键屏蔽

打开“设置 > Windows 快捷键屏蔽”，可以分别选择 `Win+A` 到 `Win+Z` 中受支持的组合。页面不提供 `Win+L`。

### 7.1 生效规则

- 点击“应用”或“保存”后立即生效，不需要重启 Windows 资源管理器。
- 只在简驭运行期间生效；退出简驭后自动解除。
- 不修改 Windows 系统策略，也不会关闭 Game Bar、反馈中心等系统功能本身。
- 左 Win 和右 Win 都适用。
- 只屏蔽精确的 `Win+字母`。例如屏蔽 `Win+Z` 不会影响 `Shift+Win+Z`、`Ctrl+Win+Z` 或 `Alt+Win+Z`。

### 7.2 与全局热键联动

如果已启用的内置或自定义热键正好是 `Win+字母`，简驭会自动开启并锁定对应的屏蔽开关，使 Windows 不再先执行原有操作，而改为执行简驭动作。

禁用、清除或删除最后一个使用该组合的全局热键后，联动锁定会解除。用户原先手动选择的独立屏蔽状态不会被覆盖。

### 7.3 无法屏蔽的范围

简驭不能屏蔽 Windows 安全桌面上的组合，例如 `Ctrl+Alt+Del` 和 `Win+L`。登录界面、其他用户会话和部分远程桌面环境也不在保证范围内。

## 8. Everything 功能

### 8.1 Everything 在简驭中的作用

Everything 提供两项能力：

1. 打开或恢复 Everything 搜索窗口。
2. 当快捷启动菜单只填写了程序名、且常规路径查找不到时，帮助定位文件系统中的可执行文件。

Everything 组件位于程序目录的 `Everything/` 下，不会嵌入 `Simpilot.exe`，也不会在运行时下载。

### 8.2 已经运行 Everything 时

简驭通过 `Everything64.dll` 连接默认 Everything 实例。若默认实例的数据库已经可用，会直接复用，不关心该 Everything 客户端安装在哪个目录。打开搜索窗口时，也会优先恢复已有窗口或使用已运行客户端的来源路径。

当前仅面向默认实例。若用户只运行了命名实例，简驭可能无法连接该数据库，并会尝试启动随包的默认实例。

### 8.3 没有运行 Everything 时

简驭会检查默认 Everything 服务：

- 服务已经安装但停止时，尝试启动服务；
- 数据库仍不可用时，尝试启动随包 `Everything/Everything.exe`；
- Everything 组件缺失或启动失败时，简驭继续运行，但 Everything 搜索和基于数据库的程序定位不可用。

“维护 > 安装/修复 Everything 服务...”会调用随包 Everything 的服务安装功能，并显示 Windows UAC 确认。取消 UAC 不会影响简驭的其他功能。

### 8.4 找到多个同名程序

Everything 找到多个有效候选时，简驭会显示带图标的选择窗口，其中包含文件路径、版本和修改时间。候选项按以下顺序排列：

1. 文件版本最高者优先；
2. 版本相同时，修改时间最新者优先；
3. 仍相同时，按完整路径的不区分大小写字母顺序排列。

选择结果会保存在 `Cache/program-cache.tsv`。目标被移动或删除后，缓存会自动失效，并在下次需要时重新查找。若之前选错，可在“设置 > 快捷启动菜单”选中对应启动项，通过“当前解析路径”旁的“重新选择...”立即修改。

## 9. 菜单图标

### 9.1 自动图标

简驭会自动为可用的应用、文件、网址和分类显示图标。首次使用某个本地目标时，自动图标会保存到 `Cache/RunIcon/`。如果程序没有 128×128 原生图标，简驭会自动缩放可用图标。

图标提取失败不会阻止启动项执行；该项目会退化为无图标文字。

### 9.2 人工指定图标

打开“设置 > 菜单图标”：

1. 在列表中选择本地启动项。
2. 点击“选择图标...”。
3. 选择 ICO 文件，或从 EXE、DLL 中选择图标。
4. 点击“应用”或“保存”。

“恢复自动图标”会移除选中项目的人工图标。人工图标按完整启动操作区分，因此同一个 EXE 使用不同参数时可以分别设置图标。

网址、分类和分隔线不在人工图标列表中；网址和分类使用自动图标，分隔线不使用图标。

> 删除整个 `Cache/RunIcon/` 会同时删除自动缓存和人工指定图标。需要保留人工图标时，请不要把该目录当作普通临时缓存整体清除。

## 10. 配置、缓存与日志

简驭运行后会在程序目录中按需创建：

```text
Config/
  Simpilot.ini
  Simpilot2.ini
  Simpilot.settings.ini
  language.txt
Cache/
  program-cache.tsv
  RunIcon/
Log/
  Simpilot.log
```

文件用途：

| 文件或目录 | 用途 |
|---|---|
| `Config/Simpilot.ini` | 主快捷启动菜单 |
| `Config/Simpilot2.ini` | 可选的第二菜单 |
| `Config/Simpilot.settings.ini` | 常规设置、热键和 Windows 快捷键屏蔽 |
| `Config/language.txt` | 当前界面语言 |
| `Cache/program-cache.tsv` | 无路径程序的已确认解析结果 |
| `Cache/RunIcon/` | 自动图标缓存和人工图标 |
| `Log/Simpilot.log` | 启动、菜单、Everything、热键和错误诊断 |

菜单配置统一使用 UTF-8。普通用户建议通过设置窗口编辑；直接编辑时，应使用支持 UTF-8 的文本编辑器。

`program-cache.tsv` 可以在简驭退出后删除，之后遇到无路径程序时会重新查找。`Simpilot.log` 只保留一个文件，简驭每次启动时会清理其中超过 90 天的记录。

迁移或备份时，最稳妥的方法是先退出简驭，再复制整个程序目录。至少应保留 `Config/`；若使用了人工图标，还应保留 `Cache/RunIcon/`。

## 11. 故障排查

### 11.1 启动后没有窗口

这是正常行为。简驭默认只显示托盘图标。请检查任务栏通知区域和隐藏图标区域。

如果托盘图标也不存在：

1. 确认已经完整解压发布包，而不是在压缩包内运行。
2. 确认程序目录可写，并保留 `Languages/` 和 `Everything/`。
3. 如果刚重启过 Windows 资源管理器，请稍候片刻；简驭会自动恢复托盘图标。
4. 再次启动 `Simpilot.exe`。
5. 查看 `Log/Simpilot.log`。

### 11.2 快捷启动菜单缺少某个项目

简驭会隐藏无法解析或不存在的启动目标。请检查：

1. 目标路径是否存在；
2. 相对路径是否以 Simpilot 配置目录为基准填写正确；
3. 程序名是否能通过 Windows 系统目录、PATH 或 Everything 找到；
4. Everything 数据库是否可用；
5. `Simpilot.ini` 是否为有效 UTF-8 配置。

修正后可等待自动刷新，或选择“维护 > 刷新菜单”。读取失败时，简驭会保留上一份有效菜单并写入日志。

### 11.3 全局热键没有响应

1. 确认该项已经录制热键并打开启用开关。
2. 点击“应用”或“保存”。
3. 关闭设置窗口后再测试。
4. 检查是否与其他应用的全局热键冲突。
5. 尝试换用不受系统保护的组合。
6. 查看 `Log/Simpilot.log` 是否有热键注册失败记录。

### 11.4 Windows 快捷键仍然执行

1. 确认对应开关已打开并已应用。
2. 确认按下的是精确的 `Win+字母`，没有同时按 Ctrl、Alt 或 Shift。
3. 确认简驭仍在运行。
4. `Win+L` 和安全桌面组合不受支持。
5. 登录界面、其他用户会话和部分远程桌面环境不在保证范围内。

此功能不需要重启 Windows 资源管理器，也不应要求修改系统策略。

### 11.5 Everything 搜索打不开

1. 确认 `Everything/Everything.exe` 和 `Everything/Everything64.dll` 都存在。
2. 在托盘右键菜单中选择“维护 > 打开 Everything”。
3. 必要时选择“安装/修复 Everything 服务...”，并完成 UAC 确认。
4. 若使用自建 Everything，请确认运行的是默认实例而不是仅运行命名实例。
5. 查看 `Log/Simpilot.log` 中的 Everything 状态和启动错误。

### 11.6 菜单图标没有更新

先重新打开快捷启动菜单。若仍未更新，可退出简驭后删除对应的自动图标缓存，再重新启动。不要直接删除整个 `Cache/RunIcon/`，除非确定不需要其中的人工图标。

### 11.7 设置或菜单无法保存

1. 确认程序目录及 `Config/` 可写。
2. 检查是否有其他程序正在修改配置文件。
3. 根据界面提示修正无效名称、空目标或网址格式。
4. 查看 `Log/Simpilot.log`。

## 12. 常见问题

### 简驭是安装软件还是便携软件？

是便携软件。完整解压后即可运行；配置、缓存和日志默认保存在程序目录中。

### 为什么程序启动后只有托盘图标？

简驭的主要入口就是托盘和全局热键，不提供常驻主面板。左键打开快捷启动菜单，右键打开设置和维护菜单。

### 菜单快捷键和全局热键有什么区别？

菜单快捷键只在快捷启动菜单已经打开时生效，用于选择当前菜单中的项目。全局热键在简驭后台运行时可从其他应用中直接触发。

### 简驭会修改 Windows 系统快捷键策略吗？

不会。“Windows 快捷键屏蔽”只在简驭运行期间实时拦截选定组合，退出后自动恢复。只有启用开机启动时会写入当前用户启动项；只有主动选择 Everything 服务安装/修复时才会请求管理员权限并更改 Everything 服务。

### 能否屏蔽或改用 Win+L？

不能。`Win+L` 属于 Windows 安全锁定快捷键，简驭不提供屏蔽或全局热键覆盖。

### 屏蔽 Win+Z 后，Shift+Win+Z 还能使用吗？

可以。独立屏蔽只匹配精确的 `Win+Z`，带有 Ctrl、Alt 或 Shift 的其他组合仍交给 Windows 或相应应用处理。

### 已安装并运行自己的 Everything，简驭会怎么处理？

只要默认实例数据库可用，简驭会优先复用它，并在打开搜索窗口时优先使用现有客户端。不会要求 Everything 必须位于 Simpilot 目录中。

### 没有 Everything，简驭还能使用吗？

可以。明确路径、Windows 系统目录或 PATH 中能够找到的项目仍可使用；Everything 搜索和依赖数据库定位的无路径程序会不可用。

### 为什么会出现同名程序选择窗口？

Everything 找到了多个同名文件，简驭无法仅凭文件名判断用户意图。选择结果会被缓存；若之后需要更换，可在快捷启动菜单编辑器中查看当前解析路径并点击“重新选择...”。

### 可以给网址或分类人工指定图标吗？

当前不可以。人工指定图标面向可解析到本地文件的启动项；网址和分类使用自动图标。

### 可以把自定义全局热键直接设置为打开网址吗？

当前自定义全局热键只支持打开应用、文件夹和文件。网址可以添加到快捷启动菜单。

### 更新版本时如何保留设置？

先退出简驭并备份原目录。更新时保留原来的 `Config/`；使用人工图标时同时保留 `Cache/RunIcon/`。请继续保持 `Everything/` 和 `Languages/` 与新版 `Simpilot.exe` 配套，不要只替换或单独移动部分组件。

### 可以删除缓存和日志吗？

退出简驭后可以删除 `Cache/program-cache.tsv` 和 `Log/Simpilot.log`，程序会按需重新创建。删除 `Cache/RunIcon/` 也会重建自动图标，但其中的人工图标会一起丢失。

## 13. 卸载

简驭没有控制面板卸载项。卸载前按以下顺序操作：

1. 打开“设置 > 常规”，关闭“登录 Windows 后自动启动简驭 | Simpilot”，点击“应用”。
2. 若曾通过简驭的维护菜单安装随包 Everything 服务，请先卸载该服务；简驭当前没有单独的“卸载服务”按钮。可在管理员 PowerShell 或命令提示符中进入 Simpilot 目录并执行：

   ```powershell
   .\Everything\Everything.exe -uninstall-service
   ```

   如果使用的是自己原有的 Everything 服务，不要执行这一步。
3. 右键托盘图标，选择“退出”。
4. 删除整个 Simpilot 目录。

删除程序目录会一并删除 `Config/`、`Cache/` 和 `Log/` 中的个人配置、人工图标与日志。需要保留时请提前备份。

## 14. 获取诊断信息

遇到问题时，首先查看：

```text
Log/Simpilot.log
```

向开发者反馈时，建议同时说明：

- Simpilot 版本（托盘右键 > 关于）；
- Windows 版本；
- 问题发生前执行的操作；
- 能否稳定复现；
- 相关界面截图；
- `Simpilot.log` 中问题发生时间附近的记录。

日志可能包含程序路径和配置目标。公开提交前，请先检查并遮盖不希望公开的个人目录名或文件名。

问题与建议可提交到 [GitHub Issues](https://github.com/wonly211/Simpilot/issues)。
