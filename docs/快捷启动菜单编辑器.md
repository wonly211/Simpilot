# Simpilot 可视化快捷启动菜单编辑器

## 目标与边界

当前版本通过“设置 > 快捷启动菜单”提供可视化编辑器，用原生 Win32 窗口直接维护主菜单和第二菜单。编辑器不会引入数据库或新的菜单格式：`Config/Simpilot.ini` 与可选的 `Config/Simpilot2.ini` 仍是唯一数据源，并统一按 UTF-8 读写。以下版本记录仅作为设计演进背景。

0.9.1 修复每次修改菜单结构后左侧菜单树未立即重绘的问题。树形控件现在会暂停绘制后批量重建节点，恢复原选择并立即完成整体刷新，不再依赖鼠标滚轮等后续输入触发重绘。

0.9.2 将配置中末尾的 `(&字符)` 识别为菜单访问键；Simpilot 保存时自动生成后缀，并将访问键注册到 Windows 菜单。

0.10.0 将已存在条目的编辑改为右侧内嵌表单：选择分类或启动项后可直接修改内容，不再弹出编辑窗口。左侧为结构操作区，顶部用于添加分类、启动项和分隔线，底部用于移动及调整层级；左右区域之间可拖动分隔条以调整编辑空间。在 0.11.0 中，这个区域移除了重复标题，树区默认更宽，并将“上移、下移、升级、降级”收纳为单行操作按钮。

## 编辑能力

- 在“主菜单”和“第二菜单”标签之间切换。
- 添加应用、文件夹、文件和网址启动项。
- 添加分类与分隔线，并通过“升级”“降级”调整嵌套关系。
- 直接在右侧编辑或删除已有条目，通过“上移”“下移”明确调整同级顺序。
- 启动项和分类都可设置一个菜单访问键；应用条目还可设置命令行参数和管理员运行标记，文件夹、文件及网址使用对应的直接打开方式。
- 左侧树在分类和启动项名称后显示已配置的菜单访问键，例如 `常用工具  [A]`。同一分类下重复的访问键字符以黄色提示；该提示不阻止保存，不同层级互不影响。
- 人工图标只在“设置 → 菜单图标”页管理，编辑器不提供图标选择或恢复功能。

编辑器采用按钮操作而非拖拽，避免树形菜单中拖放目标和层级含义不明确。分类和分隔线不能指定图标。

## 配置格式与校验

保存内容遵循现有菜单格式：

```text
-常用工具(&A)
记事本(&N)|notepad.exe
管理员终端(&T)[#]|wt.exe
--子分类
项目目录|"D:\Work Files"
--
OpenAI|https://openai.com/
```

分类行以连字符数量表示层级；单独的层级标记用于返回父级，`|` 表示分隔线，名称后的 `[#]` 表示以管理员身份运行。名称末尾的 `(&A)` 表示菜单访问键 `A`，该后缀由编辑器根据独立输入框自动生成，用户不需要手动输入。菜单打开时按对应字符可选择分类或执行启动项，Windows 会以下划线标识该字符。普通启动项名称不能以 `[#]` 结尾，以免与管理员标记产生歧义。名称和目标必须为单行文本，分类名不能以连字符开头或包含首尾空白，网址必须使用 `http://` 或 `https://`。

路径包含空格时，编辑器会按命令格式自动加引号。保存前会校验两份菜单；任意一份无效时均不会写入。发生结构修改并保存时，编辑器会按规范格式重新生成配置，原文件中的注释和空行不作为菜单内容保留；未修改菜单时点击“保存”不会重写文件。

## 保存与冲突处理

编辑器打开时记录两份源配置。保存前若检测到文件被其他程序修改，会要求用户明确确认，避免无提示覆盖外部变更。确认保存后，先生成完整 UTF-8 内容，再通过同目录临时文件原子替换目标配置。Simpilot 随后重新加载菜单；保存失败时保留原配置。

关闭含未保存修改的编辑器时会要求确认。右侧内容在当前编辑会话中即时更新，只有点击编辑器底部的“保存”才会写入配置文件。

## 人工图标身份

人工图标以配置中的完整启动操作为身份，包括条目类型、原始目标或命令、参数和管理员状态。同一个 EXE 的不同参数、不同 `explorer.exe shell:::{GUID}` 命令，以及不同浏览器应用条目均可分别指定图标。修改启动操作后，请在“设置 → 菜单图标”页为新操作单独指定图标。
