# 第五个“馭”字等宽矢量稿

参考图：`reference-manual-denoise.png`

正式矢量：`yu-fifth-equal-stroke.svg`

## 矢量规则

- 画布比例：`viewBox="0 0 512 700"`，保持参考图的纵向比例。
- 所有笔画：`stroke-width="30"`。
- 端点：`stroke-linecap="round"`。
- 转角：`stroke-linejoin="round"`。
- 图形只包含 SVG 开放路径，不包含嵌入位图。
- 左侧马部和右侧手部没有合并成填充轮廓，后续可以统一调整线宽。
